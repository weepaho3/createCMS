The upload types (`CmsMediaUploadState`, `CmsMediaUploadFileState`,
`CmsMediaUploadStatus`, `CmsMediaUploadProgress`) mirror the core upload
queue, with the new `CmsMediaUploadPhase`, `CmsMediaUploadOptions` and
`CmsMediaDuplicateDecision`. `/media` shows the new statuses, and message
catalogs carry a text for each.
