Each package ships the docs of its release as Markdown in `docs/`, generated
from the same source as createcms.dev: `docs/llms.txt` is the index for
coding agents, every page follows it, and links between shipped pages stay
inside the package. `@createcms/core` also ships the `createcms` agent skill
in `skills/createcms/SKILL.md`.
