---
title: Variables
description: Reusable values substituted into content, via cms.api.variables.
---

Variables are reusable values referenced in content as `{{key}}` and substituted on read (in `getBlockTree` and `getPublishedContent`, unless `raw: true`). Methods live under `cms.api.variables` and are mirrored on the client as `client.variables.<method>` with identical types.

A `key` is alphanumeric plus underscores. Updating a variable's `value` revalidates the published roots that use it. Deleting one that is in use throws `VARIABLE_IN_USE`.

Reference a variable in any string property, for example `{ title: 'Hello {{siteName}}' }`. An unknown key is left literal.

## Client-side substitution

The `{{key}}` helpers the server uses on read are exported as pure functions, so an editor can preview substitution from a variables map it already loaded (for example from `variables.list`) without another request. Import them from `@createcms/core` on the server and from `@createcms/core/react` in the browser.

```ts
import { extractVariableKeys, resolveTemplateString } from '@createcms/core/react';

const { variables } = await client.variables.list();
const vars = new Map(variables.map((v) => [v.key, v.value]));
resolveTemplateString('Hello {{siteName}}', vars); // 'Hello Acme'
extractVariableKeys('{{a}} and {{b}}'); // ['a', 'b']
```

`VAR_PATTERN` (the `{{key}}` regex, global) is exported as well; reset its `lastIndex` before a manual `exec` or `test`, or use `extractVariableKeys`.

## Methods

### List Variables [#list]

List every variable, ordered by key, so you can browse or search what's defined. All query fields are optional — call it with no arguments to page through everything from the top.

<APIMethod
  method="GET"
  path="/variables/list"
  fn="list"
  collection="variables"
  resource="variable"
  operation="read"
  args={`{
  query: { search: 'site', limit: 20 },
}`}
  returns={{
    variables: { type: 'Variable[]', description: 'The variables on this page, ordered by key. Each row is `{ id, key, value, description, createdBy, updatedBy, createdAt, updatedAt }`.' },
    total: { type: 'number', description: 'Total variables matching the search, ignoring limit/offset.' },
    hasMore: { type: 'boolean', description: 'Whether more variables exist after this page.' },
  }}
  params={{
    limit: { type: 'number', default: '50', description: 'Page size, 1 to 100.' },
    offset: { type: 'number', default: '0', description: 'Rows to skip.' },
    search: { type: 'string', description: 'Case-insensitive substring match against the variable key.' },
  }}
/>

### Get a Variable [#getvariable]

Fetch a single variable by its key, and find out in the same call whether it's currently referenced anywhere. Throws `VARIABLE_NOT_FOUND` if no variable has that key.

<APIMethod
  method="GET"
  path="/variables/getVariable"
  fn="getVariable"
  collection="variables"
  resource="variable"
  operation="read"
  args={`{
  query: { key: 'siteName' }, // required
}`}
  returns={{
    variable: { type: 'Variable', description: 'The variable row: `{ id, key, value, description, createdBy, updatedBy, createdAt, updatedAt }`.' },
    inUse: { type: 'boolean', description: 'Whether the variable is currently referenced by live content or a template.' },
  }}
  params={{
    key: { type: 'string', required: true, description: 'The variable key to retrieve.' },
  }}
/>

### Create a Variable [#createvariable]

Create a new variable with a unique key. You get back the created variable, including its generated id and timestamps. A duplicate key throws `VARIABLE_KEY_EXISTS`.

<APIMethod
  method="POST"
  path="/variables/createVariable"
  fn="createVariable"
  collection="variables"
  resource="variable"
  operation="create"
  args={`{
  body: {
    key: 'siteName', // required
    value: 'Acme', // required
    description: 'Public site name',
  },
}`}
  returns={{
    variable: { type: 'Variable', description: 'The newly created variable, with its generated id, timestamps, and creator metadata.' },
  }}
  params={{
    key: { type: 'string', required: true, description: 'Unique key, 1 to 100 characters, alphanumeric and underscores only.' },
    value: { type: 'string', required: true, description: 'The variable value.' },
    description: { type: 'string', description: "Optional description of the variable's purpose." },
  }}
/>

### Update a Variable [#updatevariable]

Update a variable's value and/or description. Changing the value revalidates every published root that references it, so the new value goes live automatically.

<APIMethod
  method="POST"
  path="/variables/updateVariable"
  fn="updateVariable"
  collection="variables"
  resource="variable"
  operation="update"
  args={`{
  body: {
    key: 'siteName', // required
    value: 'Acme Corp',
  },
}`}
  returns={{
    variable: { type: 'Variable', description: 'The updated variable.' },
  }}
  params={{
    key: { type: 'string', required: true, description: 'The variable key to update.' },
    value: { type: 'string', description: 'New value. Changing it triggers revalidation of published content.' },
    description: { type: 'string', description: 'New description.' },
  }}
/>

### Delete a Variable [#deletevariable]

Delete a variable by key. It fails with `VARIABLE_IN_USE` if the variable is still referenced in any live content or template, so you can't leave a dangling `{{key}}` behind.

<APIMethod
  method="POST"
  path="/variables/deleteVariable"
  fn="deleteVariable"
  collection="variables"
  resource="variable"
  operation="delete"
  args={`{
  body: { key: 'siteName' }, // required
}`}
  returns={{
    variableId: { type: 'string', description: 'The id of the deleted variable.' },
  }}
  params={{
    key: { type: 'string', required: true, description: 'The variable key to delete.' },
  }}
/>

### List Variable Usages [#getvariableusages]

Find every place a variable is referenced before you change or delete it: the distinct live block usages in branch heads and the template usages, each with a total count.

<APIMethod
  method="GET"
  path="/variables/getVariableUsages"
  fn="getVariableUsages"
  collection="variables"
  resource="variable"
  operation="read"
  args={`{
  query: { key: 'siteName' }, // required
}`}
  returns={{
    blockUsageCount: { type: 'number', description: 'Number of distinct live block usages.' },
    templateUsageCount: { type: 'number', description: 'Number of template usages.' },
    blockUsages: { type: '{ rootId, blockId, propertyKey }[]', description: 'Each distinct live block property (in a branch head) that references the variable.' },
    templateUsages: { type: '{ templateId, collection, blockType, propertyKey }[]', description: 'Each template property that references the variable.' },
  }}
  params={{
    key: { type: 'string', required: true, description: 'The variable key to inspect.' },
  }}
/>
