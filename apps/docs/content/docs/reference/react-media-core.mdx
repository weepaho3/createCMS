---
title: Media core
description: The framework-free store, layout, selection, filter and intake logic of the media library (@createcms/react/media/core).
---

`@createcms/react/media/core` is the React-free kernel of the
[media library](/docs/reference/react-media). It has no directive, no React
and no runtime dependency (a boundary test, an oxlint rule and a dist check
guard that), so servers, workers, tests in Node and other frameworks import
it. The React parts are thin bindings over it.

```ts
import { createHistoryFilterAdapter, createMediaStore, layout } from '@createcms/react/media/core';
```

## Store

`createMediaStore(options)` returns a `MediaStore`:
`{ getState, subscribe, dispatch, on, emit, registries, setUploader, client, pageSize, dispose }`.
`CreateMediaStoreOptions`: `client` (a `MediaClient`), `defaultFolderId`,
`filter`, `pageSize` (1 to `MAX_PAGE_SIZE`, default 40), `selection`
(`SelectionMode`), `keepHiddenSelection`, `layout`, `expandedStorage`
(`{ storage, key }`, errors ignored) and `onFilterChange(filter, mode)` for
URL sync. Every change replaces the state object and the changed slice, so
selectors compare by reference.

`MediaStoreState` has one slice per module:

| Slice | Type | Holds |
| --- | --- | --- |
| `collection` | `CollectionSlice` | `query` (a `FilterState`), `ids`, `byId`, `cursor`, `total`, `status` (`CollectionStatus`: `idle`, `loading`, `refreshing`, `appending`, `error`), `error`. |
| `selection` | `SelectionSlice` | A `SelectionState` plus `hidden`. |
| `folders` | `FolderTreeState` | `nodes` (`FolderNode`), `roots`, `expanded`, `loading`, `currentId`, `path`. |
| `preview` | | `openId`, `ids` (the collection order when it opened), `zoom`, `pan`, `rotation`. |
| `detail` | | `assetId`, `asset`, `draft` (`DetailDraft`), `dirty`, `baseUpdatedAt`, `saving`, `error`, `conflict` (the newer server asset), `revisions` (`MediaRevision[]`). |
| `ui` | | `layout` (`LayoutMode`), `viewport`. |
| `mutation` | | `status`, `error`, `skipped`, `skippedReasons` of the last bulk change. |

`dispatch(command)` runs a `MediaCommand` and resolves with a
`CommandResult`: `{ ok: true, value?, skipped?, undo? }` or
`{ ok: false, code, error }` with a `MediaErrorCode` (or the server's code).
Commands: `init` (optionally with the URL `filter`, applied without writing
it back), `load`, `loadMore`, `refresh`, `setFilter` (`replace`, `debounce`
for typing, `silent` for history navigation), `openFolder`, `loadFolders`,
`expandFolder`, `collapseFolder`, `select` (with `SelectionModifiers`),
`toggleSelection`, `extendSelection`, `focus`, `setSelection`, `selectAll`,
`selectAllMatching`, `clearSelection`, `move`, `archive`, `restore`,
`setVisibility`, `setProvenance`, `updateAsset`, `createFolder`,
`renameFolder`, `moveFolder`, `deleteFolder`, `receive`, `assetUploaded`,
`openPreview`, `closePreview`, `previewStep`, `previewZoom`,
`previewRotate`, `openDetail` (fetches the asset when it is not loaded),
`closeDetail`, `setDetailField`, `resetDetail`, `saveDetail` (sends the
changed fields with `expectedUpdatedAt`; an `ASSET_CONFLICT` keeps the
draft and sets `conflict`), `resolveDetailConflict` (`keep: 'mine'` saves
over the newer version, `'theirs'` drops the draft), `setFocalPoint`,
`loadRevisions`, `setCurrentRevision`, `purge` (`ids`, `reason`), `setLayout`, `setViewport`,
`clearMutationError`.

List requests are aborted when a newer one starts; a filter change keeps the
old results visible as `refreshing`; typing waits `SEARCH_DEBOUNCE_MS` (250).
Appended pages do not count again (`total` comes from the first page). Move,
archive and visibility changes patch the collection optimistically, roll back
on failure, restore the ids the server skipped, move the focus to the next
item after a removal and return an `undo` where the change is invertible.
With `allMatching` selected, bulk commands send the filter instead of ids.
`client.subscribe` events (`MediaServerEvent`) are reconciled: updated and
replaced assets are refetched, archived ones removed, folder changes relist
the affected levels. `dispose()` cancels timers, requests and the
subscription; `init` resumes, so a React StrictMode remount works.

`on(type, listener)` subscribes to a `MediaEvent` (`MediaEventType`):
`asset:uploaded`, `asset:updated`, `asset:replaced`, `asset:moved`,
`asset:archived`, `asset:restored`, `asset:purged`, `folder:changed`, `selection:changed`.

`receive` queues files through `setUploader(upload)` (a `MediaUploader`,
the client's `upload`): file hooks run first, and with `recreateFolders` the
relative folders of a drop are created parents first and every file is
uploaded into its folder.

Selectors: `collectionAssets(state)` (the loaded assets in order),
`currentFolders(state)` (subfolders of the open folder) and
`emptyReason(state)` (`folder-empty`, `no-results`, `error`,
`no-permission` or `null`).

### Registries

`store.registries` (`MediaRegistries`) holds four `Registry`s
(`createRegistry`: `register` replaces by `id` and returns the unregister,
`list`, `get`, `subscribe`):

| Registry | Item | Use |
| --- | --- | --- |
| `sources` | `MediaSource` | Extra places to get files from (URL import, a DAM); `open({ receive })`. |
| `fileHooks` | `MediaFileHook` | `transform(files)` before files are queued (rename, resize, reject). |
| `assetActions` | `BulkAction` | Bulk and item actions (below). |
| `previewRenderers` | `MediaPreviewRenderer` | `match(asset)` and a framework-specific `render`. |

### Bulk actions

A `BulkAction` is `{ id, label, scope?, canExecute(context), confirm?(context), run(context, input) }`.
`canExecute` returns `true` or a reason code; `confirm` a
`ConfirmDescriptor` (`{ kind, count, destructive?, items?, requireTyping? }`).
`bulkContext(store, itemId?, state?)` builds the `BulkContext`
(`{ store, state, ids, count, assets, target }`); `BulkInput` carries
`folderId`, `force`, `provenance`, `open`, `name` and `reason`. Built-ins:
`moveAction`, `makePublicAction`, `makePrivateAction`, `setProvenanceAction`,
`downloadAction` (one asset through `?download=true` on the asset endpoint,
several as one archive through `downloadQueueOf(store)`, the queue every
surface of a store shares, `null` without `downloadIntent`), `archiveAction`
`restoreAction` and `purgeAction` (erases the selection with
`purgeAssets`; its confirmation asks to type `purge`, `input.reason` is
the reason code, default `erasure`), in `builtInBulkActions`;
`registerBuiltInBulkActions(store)` adds them. `archiveInUseConfirm(reasons)`
describes the confirmation for assets an archive skipped because they are in
use.

## Filter

`FilterState` drives the query, the URL and shareable views: `q`, `kinds`
(`MediaKind`), `mime`, `folderId`, `recursive`, `unfiled`, `provenance`
(`AssetProvenance`), `visibility` (`AssetVisibility`), `processingState`
(`ProcessingState`), `uploadedBy`, `createdFrom`, `createdTo`, `sizeMin`,
`sizeMax`, `widthMin`, `heightMin`, `orientation` (`Orientation`), `usage`,
`usageScope`, `missingAlt`, `expiringWithinDays`, `archived` and `sort`
(`FilterSort`, one of `FILTER_SORTS`). `DEFAULT_FILTER` sorts newest first;
`MEDIA_KINDS` and `ASSET_PROVENANCES` list the values.

| Function | Does |
| --- | --- |
| `encodeFilter(filter)` | The query string with short keys: `q`, `type=image,video`, `folder` (`ROOT_FOLDER_PARAM` for the root), `from`, `to`, `size=0-5mb`, `usage=unused`, ... The default sort is left out. |
| `parseFilter(search, base?)` | Reads a query string; unknown keys and invalid values are ignored. `parseFilter(encodeFilter(f))` equals `normalizeFilter(f)`. |
| `normalizeFilter(filter)` | One shape for equal filters (no empty values or impossible combinations). |
| `filtersEqual(a, b)`, `activeFilterCount(filter)` | Equality; filters beyond folder, sort and text. |
| `formatSizeParam(bytes)`, `parseSizeParam(text)` | `5mb` and back. |
| `filterToQuery(filter)`, `sortOfFilter(sort)` | The `listAssets` parameters and sort. |
| `isPlainFolderView(filter)` | Only folder and sort set. |

A `FilterUrlAdapter` is `{ read(), write(filter, mode), subscribe? }` with
`FilterWriteMode` `replace` (typing) or `push` (discrete changes).
`createHistoryFilterAdapter({ prefix?, window? })` mirrors the filter in
`location.search` and keeps query parameters it does not own;
`createMemoryFilterAdapter(initial?)` keeps it in memory (a picker never
touches the URL).

## Layout

`layout(viewport, items, options)` lays out `LayoutItem`s
(`{ id, width?, height? }`) without measuring the DOM and returns a
`CollectionLayout`: `rows` (`LayoutRow`: `index`, `top`, `height`, `items`),
`rects` (`Rect` per item, content coordinates), `rowOf`, `columns`,
`totalHeight`, `rowHeight` and, for masonry, `laneOf`. `LayoutOptions`:
`mode` (`LayoutMode`: `grid`, `justified`, `masonry`, `list`), `gap`,
`minCell`, `aspect`, `targetRowHeight` (180 to 240), `listRowHeight` (48 to
56), `rtl`. Grid columns are `columnCount(width, minCell, gap)` =
`floor((width + gap) / (minCell + gap))`.

`navigate(layout, index, key, { rtl, viewportHeight })` returns the item a
`NavigationKey` moves to, never outside the items: up and down keep the
column (grid, list, clamped into a short last row), the lane (masonry) or the
closest horizontal center (justified); page keys move by the rows that fit.
`navigationKeyOf(key, ctrlOrMeta)` maps `KeyboardEvent.key`.
`visibleRows(layout, scrollTop, viewportHeight, overscan)` is the mounted
range, `itemsInRect(layout, rect)` a hit test over all rects and
`intersects(a, b)` the rect test.

## Selection

`SelectionState` is `{ mode, selected, anchor, rangeEnd, focus, allMatching }`
(`SelectionMode`, `AllMatching` = `{ query, except }`), from
`createSelection(mode)`.

| Function | Does |
| --- | --- |
| `selectionClick(state, order, id, modifiers)` | A click: replace; Cmd/Ctrl toggles; Shift replaces the previous range from the anchor (Finder); both add a range. |
| `toggleSelection`, `focusSelection`, `extendSelection` | Space, Cmd/Ctrl+Arrow, Shift+Arrow. |
| `selectAllLoaded`, `selectAllMatching`, `clearSelection` | Cmd/Ctrl+A, every match on the server, Escape. |
| `reconcileSelection(state, visible, options)` | After a filter or removal: drops hidden ids unless `keepHidden` (then counts them). |
| `isSelected`, `selectionCount(state, total)` | Membership and count, unloaded `allMatching` assets included. |
| `bulkTarget(state)` | The `BulkTarget` a bulk endpoint receives. |
| `dragIds(state, id)` | The selection when `id` is part of it, else `id` alone. |
| `nextFocusAfterRemoval(order, removed, focus)` | The next remaining id, else the previous one. |

## Marquee

`marqueeRect(start, current)` and `marqueeActivated(start, current)` (after
`MARQUEE_ACTIVATION_PX`) work on `Point`s; `marqueeHits(layout, ids, rect)`
hit-tests every layout rect, mounted or not; `applyMarquee(base, hits, mode)`
applies a `MarqueeMode` (`marqueeModeOf`: no modifier replaces, Shift adds,
Cmd/Ctrl toggles) to the selection at the start of the gesture.
`autoScrollDelta(pointer, start, size, msInBand)` scrolls in an edge band of
`min(AUTO_SCROLL_BAND_RATIO, AUTO_SCROLL_BAND_MAX_PX)` at up to
`AUTO_SCROLL_MAX_PX` per frame, ramped up over `AUTO_SCROLL_RAMP_MS`.

## Folders

`createFolderTree(currentId)` and `setFolderChildren(state, parentId, folders)`
build the tree from `FolderRecord`s; `mayHaveChildren(node)` reads
`folderCount`. `folderTreeRows(state)` lists the visible `FolderTreeRow`s
(level, set size, position, expanded, loading); `treeNavigate(rows, id, key)`
applies an APG tree `TreeKey` (`treeKeyOf`) and returns a `TreeKeyResult`
(`focus`, `expand`, `collapse`). `moveRejection(nodes, targetId, move)`
returns a `MoveRejectReason` (`same-folder`, `into-itself`) with
`isSelfOrDescendant`; `collapseBreadcrumbs(path, max)` splits a deep path;
`loadExpanded` and `saveExpanded` persist the expanded set, ignoring storage
errors.

## Intake

`normalizeDrop(dataTransfer, options)` returns an `IntakeResult`
(`{ files, folders, skippedSystem, truncated }`, files as `IntakeFile`
`{ file, relativePath }`): it collects every entry synchronously
(`collectDrop`, call it inside `drop`) and then reads directories batch by
batch (`readDrop`). It works on `DataTransferLike`, `DataTransferItemLike`
and `EntryLike`, so tests pass fakes. `IntakeOptions`: `maxFiles` (500),
`maxDepth` (10), `maxTotalBytes`, `skipSystemFiles`, `onProgress`; a limit
sets `truncated` (`IntakeLimitReason`). `normalizeInput(files)` does the same
for file and folder inputs (`webkitRelativePath`), `normalizePaste(clipboard,
now)` renames screenshots with `pastedFileName(date, ext)`.
`isSystemFile(path)`, `isTextInput(target)`, `dragHasFiles(types)`,
`dragFilePreview(dataTransfer)` and `folderOfPath(path)` help the parts.

`validate(file, constraints, dimensions?)` returns an `IntakeRejectReason`
(`type`, `size`, `count`, `dimensions`, `aspect`) for `IntakeConstraints`
(`accept`, `maxSize`, `maxFiles`, `minWidth`, `minHeight`, `maxWidth`,
`maxHeight`, `aspect`, `aspectTolerance`); `validateBatch(items, constraints)`
splits a batch into accepted items and `IntakeRejection`s; `acceptsFile`
mirrors the `accept` attribute.

## Drag payload

`ASSET_DRAG_TYPE` is `application/x-createcms-asset+json`.
`writeAssetDrag(dataTransfer, assets)` writes an `AssetDragPayload`
(`{ ids, version: 1 }`) for `DragAsset`s, `text/uri-list`, `text/plain` and,
for one asset with a URL, `DownloadURL`. A drop target checks
`hasAssetDrag(types)` in `dragover` and reads `readAssetDrag(dataTransfer)` in
`drop` (`parseAssetDragPayload` validates).

## Preview

`previewKindOf(mimeType)` returns the `PreviewKind` renderer: `image`,
`svg` (through `img`, where scripts and external resources are off),
`video`, `audio`, `pdf` or `fallback`. Zoom stays within `PREVIEW_MIN_ZOOM`
(1) and `PREVIEW_MAX_ZOOM` (8): `clampZoom(zoom)`, `stepZoom(zoom, 'in' |
'out' | 'reset')` by `PREVIEW_ZOOM_STEP` (1.25) and `toggleZoom(zoom,
natural)` between fit and the natural size. `previewStep(ids, id, delta)`
is the next or previous id without wrapping (`null` at the ends) and
`previewNeighbours(ids, id)` the ids to preload. `swipeOf(dx, dy, ms,
{ rtl, zoomed })` returns a `SwipeResult` (`next`, `prev`, `close` for a
downward swipe, or `null`): a swipe travels `SWIPE_DISTANCE_PX` (50) or
moves faster than `SWIPE_VELOCITY_PX_MS` (0.5), is mirrored in right-to-left
layouts and never counts while zoomed. `rotateQuarter(rotation)` turns by
90 degrees.

## Detail

`detailValues(asset)` reads the form values (`DetailValues`: `originalName`,
`description`, `rights` as `AssetRights`, `provenance` as
`AssetProvenanceValue`, and `custom`, the project's own metadata keys).
A `DetailDraft` holds only what changed: `setDraftField(draft, field,
value)` sets a `DetailField` (`originalName`, `description`, `provenance`,
`rights.<key>`, `custom.<key>`), `draftValue(values, draft, field)` reads
the current value and `isDirty(values, draft)` compares (an empty string
equals a missing value). `assetPatch(asset, draft)` turns the draft into an
`updateAsset` patch (an `AssetPatch`: `originalName`, `metadata`,
`provenance`) or `null`: cleared values become `null`, which removes
the key on the server, and rights carry only the changed keys.
`assetFacts(asset)` returns the read-only `AssetFacts` (type, size,
dimensions, name, uploader, date, `provenanceSource`, `c2pa`). A
`DetailSuggestion` (`{ field, value, source }`) is shown next to a field
until accepted.

## Focal point and crop

A `FocalPoint` is `{ x, y }` in fractions of the width and height; `CENTER`
is the middle. `clampFocal(point)` keeps it inside the image,
`nudgeFocal(point, direction, large)` moves it 1 or 10 percent,
`focalFromPointer(clientX, clientY, box)` places it under a pointer,
`focalPercent(point)` rounds to whole percents for labels and
`focalObjectPosition(point)` is the CSS `object-position`.

A `UsageCrop` is `{ x, y, width, height }` in fractions of the original,
stored with each use. `defaultCrop(aspect, width, height, focal)` is the
largest crop of an aspect ratio centered on the focal point and kept inside
the image; `normalizeCrop(crop)` clamps and rounds; `isFullCrop(crop)` is
true for the whole image; `cropAspect(crop, width, height)` is its aspect in
pixels; `zoomCrop(base, zoom, center)` shrinks a crop for a zoom from 1 to
3. `cropStyles(crop, image)` returns the CSS to show a crop:
`objectViewBox` (`inset(...)`) where `object-view-box` is supported, else
`image` styles for an absolutely placed image in a clipping wrapper, plus
the `aspectRatio`. `DEFAULT_CROP_PRESETS` lists `CropPreset`s
(`{ id, label, aspect, minWidth }`): Open Graph (1200 wide), square, 16:9,
4:3 and 4:5.

## Image field

An `ImageFieldValue` is a bare asset id or an `ImageRef` (`assetId`, `alt`,
`decorative`, `altSource`, `caption`, `revisionId`, `crop`, `focal`), the
`AssetRef` stored on a block. `toImageRef(value)` normalizes it.
`altStateOf(value)` is the `AltState`: `present`, `decorative` or
`missing`; `satisfiesAlt(value, requireAlt)` gates saving. `setAlt`
records typed text as the person's (`altSource: 'user'`), `setDecorative`
and `setCaption` change the other fields. `acceptAltSuggestion(value,
text)` only fills an empty, non-decorative alt text and marks it
`ai-suggested`. `replaceImageAsset(value, assetId, { keepCrop })` keeps alt
text and caption when another asset is chosen and drops the revision pin
and, unless kept, the crop. `suggestAlt(adapters, input)` asks
`AltSuggestAdapter`s in order (`suggest({ assetId, context })` with an
`AltSuggestContext`: field type, surrounding text, page title, locale, link
target) and returns the first answer; adapter errors count as none.

## Picker

`PickerConstraints`: `mode`, `min`, `max`, `accept`, `maxBytes`,
`minWidth`, `minHeight`, `aspect` (`{ ratio, tolerance }`), `allowUpload`,
`folderId`, `filters`, `cropPreset`, `requireAlt`.
`pickerDisabledReason(asset, constraints, selected)` returns the
`PickerDisabledReason` (`type`, `size`, `dimensions`, `aspect` or `max`,
the same codes as intake rejections) or `null`; `canConfirmPicker
(constraints, selected)` checks the count. `pickerFilter(constraints)` is
the listing `FilterState` (MIME types, folder, minimum dimensions) and
`intakeConstraintsOf(constraints)` the `IntakeConstraints` for uploads in
the picker.

Before a replace, `replaceWarnings(asset, file, usage)` lists
`ReplaceWarning`s: `type` when the MIME type changes, `aspect` when the
aspect ratio differs by more than `REPLACE_ASPECT_TOLERANCE` (2 percent),
`usage` when pages use the asset. `aspectLabel(aspect)` formats a ratio
(`4:3`, `1.85:1`).

## Downloads

`createDownloadQueue({ sign, fetch, sink, concurrency })` returns a
`DownloadQueue` (`getState`, `subscribe`, `download(assets, options)`,
`cancel(jobId?)`, `clear`). `download` takes `DownloadAsset`s (`id`,
`name`, `size`, `folderPath`) and `DownloadOptions` (`name`, `flatten`,
`manifest`, `usage`) and resolves with the finished `DownloadJob`
(`status` a `DownloadJobStatus`, `items` of `DownloadItem` with a
`DownloadItemStatus`, `loaded`, `total`, `sink`, `error`); the state is a
`DownloadState`. Files are signed in batches of `DOWNLOAD_SIGN_BATCH` (20)
just before they are fetched (a `DownloadSigner` returning
`SignedDownload`s), fetched `DOWNLOAD_CONCURRENCY` (3) ahead and written in
order; a file that is missing or fails is skipped and the archive shrinks
accordingly. Archive paths keep the folder path unless `flatten`, are made
safe and unique, and `manifest` adds `manifest.csv`.

With an `exporter` (a `DownloadExporter`: `create(assetIds, options)`,
`get(exportId)`, optional `delete(exportId)`, each resolving with a
`ServerExport`), the archive is written on the server instead from
`SERVER_EXPORT_FILES` (500) files on, on iOS, and when the browser can
neither stream to a file nor hold the archive in memory. The job's `sink`
is then `server`; it polls every `SERVER_EXPORT_POLL_MS` (2 s), reports the
server's byte progress, marks assets the server left out as `skipped` and
opens the signed URL once the archive is ready. Cancelling deletes the
export. The library passes an exporter when the client has
`createZipExport` and `getZipExport`, whose response is a
`MediaZipExport`.

A `DownloadSink` is `{ kind, writable, finish }`: `fileSink(name)` streams
to a file the user picks (`showSaveFilePicker`, `null` where unsupported),
`blobSink(name, size)` collects in memory and saves through a link, refused
above `BLOB_DOWNLOAD_LIMIT` (2 GB) or `BLOB_DOWNLOAD_LIMIT_IOS` (500 MB),
and `chooseSink(name, size)` takes the first that works. Failures are a
`DownloadError` with the code `DOWNLOAD_TOO_LARGE`, `DOWNLOAD_UNSUPPORTED`
or `DOWNLOAD_FAILED`.

## ZIP

`makeZip(entries)` streams a ZIP of `ZipInput`s (`name`, `lastModified`,
`input` as bytes, a `Blob`, a stream or a function returning one). Entries
are stored uncompressed (media is compressed already) with UTF-8 names and
data descriptors, and ZIP64 records where a size, an offset or the count
needs them, so `predictZipLength(entries)` knows the exact length up front.
`crc32(bytes, crc)` continues a CRC-32. `sanitizeZipPath(path)` drops `..`
and `.` segments, leading slashes, control characters, the characters
Windows rejects and trailing dots, and prefixes reserved Windows names;
`uniqueZipPaths(paths)` appends ` (2)`, ` (3)` per folder,
case-insensitively; `manifestCsv(rows)` writes a CSV that spreadsheet apps
do not evaluate as formulas.

## Touch

`createLongPress(onLongPress, { delay, tolerance })` returns a `LongPress`
(`down`, `move`, `up`, `cancel`, `consumeClick`, `fired`) that fires for
touch and pen after `LONG_PRESS_MS` (500) unless the pointer moved more
than `LONG_PRESS_TOLERANCE_PX` (10). `vibrateTick()` gives a short haptic
tick where available. `cameraAccept(kind)` is the `accept` of a camera
input with the explicit type first, which Android needs to offer the
camera.

## Announcements

An `Announce` is `(message, politeness?)` with `Politeness` `polite` or
`assertive`. `createProgressAnnouncer(announce)` returns a
`ProgressAnnouncer` (`start`, `update(percent, now, message)`, `end`) that
speaks at `PROGRESS_THRESHOLDS` (25, 50, 75) or every
`PROGRESS_HEARTBEAT_MS`, at most `MAX_PROGRESS_ANNOUNCEMENTS` times, a jump
over several thresholds once. `progressValueNow(percent)` rounds to 10 percent
steps, `batchPoliteness(failed, total)` is assertive only when everything
failed, and `createDebouncedAnnouncer(announce, delay)` (a
`DebouncedAnnouncer`, default `SELECTION_ANNOUNCE_MS`) speaks the last message
of a burst.

## Type-ahead and errors

`createTypeAhead(timeout)` returns a `TypeAhead` buffering keys within
`TYPE_AHEAD_MS`; `isTypeAheadKey(key, modifiers)` and
`matchTypeAhead(labels, from, search)` find the next label. `errorCodeOf(error)`
reads the code of a thrown client error and `isAbortError(error)` recognizes
an aborted request.

## Types

`MediaClient` and its data types are shared with
[`@createcms/react/media`](/docs/reference/react-media#client-shape):
`MediaAsset`, `MediaFolder`, `MediaAssetListQuery`, `MediaAssetFilterQuery`,
`MediaAssetListResult`, `MediaAssetStatus`, `MediaSortBy`,
`MediaSortDirection`, `MediaAllMatching`, `MediaBulkTarget`, `MediaFacets`,
`MediaServerEvent`, `MediaUploadState`, `MediaUploadEntry`,
`MediaUploadedAsset`, `MediaRevision`, and the usage types `MediaUsagePage`, `MediaUsageItem`,
`MediaUsageOccurrence`, `MediaExternalUsage` and `MediaUsageScope`.
