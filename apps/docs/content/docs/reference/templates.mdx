---
title: Templates
description: Per-property default values, via cms.api.templates.
---

A template is a default value for a block property in a given collection and block type. Template strings can contain `{{key}}` [variables](/docs/reference/variables), resolved when applied. Templates are keyed by `(collection, blockType, propertyKey)`. Methods live under `cms.api.templates` and mirror on the [client](/docs/reference/client-api) as `client.templates.<method>` with identical types.

Templates are not versioned content, so these methods do not return a `commit` envelope. A template can only target a text property (`string` or `richText`); pointing one at any other property type throws `TEMPLATE_PROPERTY_INVALID`.

## Methods

### `list`

Lists templates, ordered by collection then block type, optionally filtered by collection, block type, and a case-insensitive substring match on the template string. All query fields are optional.

<APIMethod method="GET" path="/templates/list" resource="template" operation="read" returns="{ templates, total, hasMore }" params={{
  collection: { type: 'string', description: 'Filter by collection name.' },
  blockType: { type: 'string', description: 'Filter by block type.' },
  search: { type: 'string', description: 'Case-insensitive substring match on the template string.' },
  limit: { type: 'number', default: '50', description: 'Page size.' },
  offset: { type: 'number', default: '0', description: 'Rows to skip.' },
}} />

```ts
const { templates, total } = await cms.api.templates.list({
  query: { collection: 'pages', blockType: 'hero', limit: 20 },
});
```

### `getTemplate`

Retrieves a single template by id. Throws `TEMPLATE_NOT_FOUND` if it does not exist.

<APIMethod method="GET" path="/templates/getTemplate" resource="template" operation="read" returns="{ template }" params={{
  templateId: { type: 'string', required: true, description: 'The template id.' },
}} />

### `getTemplateDefaults`

Resolves the default values for every template defined on a collection and block type, substituting `{{key}}` variables. Returns a `defaults` object mapping each `propertyKey` to its resolved string; empty when no templates exist for the pair.

<APIMethod method="GET" path="/templates/getTemplateDefaults" resource="template" operation="read" returns="{ defaults }" params={{
  collection: { type: 'string', required: true, description: 'The collection name.' },
  blockType: { type: 'string', required: true, description: 'The block type.' },
}} />

```ts
const { defaults } = await cms.api.templates.getTemplateDefaults({
  query: { collection: 'pages', blockType: 'hero' },
});
```

### `resolveTemplate`

Resolves an arbitrary template string against the current variables, substituting `{{key}}` placeholders with their stored values. Unknown placeholders are left literal.

<APIMethod method="GET" path="/templates/resolveTemplate" resource="template" operation="read" returns="{ resolved }" params={{
  template: { type: 'string', required: true, description: 'The template string to resolve.' },
}} />

### `createTemplate`

Creates a template for a `(collection, blockType, propertyKey)` triple and records the variable keys used in the template string. The target property must be a `string` or `richText` property, otherwise it throws `TEMPLATE_PROPERTY_INVALID`. Creating a duplicate `(collection, blockType, propertyKey)` throws `TEMPLATE_KEY_EXISTS`.

<APIMethod method="POST" path="/templates/createTemplate" resource="template" operation="create" returns="{ template }" params={{
  collection: { type: 'string', required: true, description: 'The collection name.' },
  blockType: { type: 'string', required: true, description: 'The block type.' },
  propertyKey: { type: 'string', required: true, description: 'The property key this template applies to.' },
  template: { type: 'string', required: true, description: 'The template string, may include `{{key}}` variable placeholders.' },
  description: { type: 'string', description: 'Optional description.' },
}} />

```ts
const { template } = await cms.api.templates.createTemplate({
  body: {
    collection: 'pages',
    blockType: 'hero',
    propertyKey: 'title',
    template: 'Welcome to {{siteName}}',
  },
});
```

### `updateTemplate`

Updates a template's string and/or description, re-syncing tracked variable usages when the string changes. Omitted fields keep their current value. Throws `TEMPLATE_NOT_FOUND` if it does not exist.

<APIMethod method="POST" path="/templates/updateTemplate" resource="template" operation="update" returns="{ template }" params={{
  templateId: { type: 'string', required: true, description: 'The template id.' },
  template: { type: 'string', description: 'New template string. Omit to keep the current value.' },
  description: { type: 'string', description: 'New description. Omit to keep the current value.' },
}} />

### `deleteTemplate`

Deletes a template by id. Throws `TEMPLATE_NOT_FOUND` if it does not exist.

<APIMethod method="POST" path="/templates/deleteTemplate" resource="template" operation="delete" returns="{ templateId }" params={{
  templateId: { type: 'string', required: true, description: 'The template id.' },
}} />
