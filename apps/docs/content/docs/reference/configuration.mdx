---
title: Configuration
description: Every option accepted by createCMS, and what it returns.
---

`createCMS(definition)` builds a configured CMS instance. The definition is typed as `CMSDefinition` (see `packages/cms/src/core/types/definitions.ts`).

```ts
import { createCMS } from '@createcms/core';

export const cms = createCMS({
  db,
  collections,
  media,
  authMiddleware,
});
```

## Options

| Option               | Type                                    | Required | Default          | Description                                                                                                                                                                                                                                                                                                                                      |
| -------------------- | --------------------------------------- | -------- | ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `db`                 | `DrizzleInstance`                       | yes      |                  | Your Drizzle (PostgreSQL) database instance.                                                                                                                                                                                                                                                                                                     |
| `collections`        | `Record<string, CollectionDefinition>`  | yes      |                  | The collections, usually grouped with `defineCollections`.                                                                                                                                                                                                                                                                                       |
| `media`              | `MediaConfig`                           | yes      |                  | S3-compatible storage config (see below).                                                                                                                                                                                                                                                                                                        |
| `authMiddleware`     | `CMSMiddleware`                         | yes      |                  | Resolves the user and permissions per request. `createCMS` throws without it; pass [`allowAnonymous()`](/docs/resources/security#authentication-is-required) to run with no auth on purpose.                                                                                                                                                     |
| `plugins`            | `CMSPlugin[]`                           | no       | `[]`             | Server plugins — see [Building plugins](/docs/plugins/building).                                                                                                                                                                                                                                                                                 |
| `basePath`           | `string`                                | no       | `'/api/cms'`     | Base path the router mounts under.                                                                                                                                                                                                                                                                                                               |
| `dataRetention`      | `DataRetentionConfig`                   | no       |                  | Pruning policy for old commits and archived roots.                                                                                                                                                                                                                                                                                               |
| `forceCommitMessage` | `boolean`                               | no       | `false`          | Require a non-empty `message` on every content mutation (create/update/delete/move/duplicate of roots and blocks). An empty or whitespace-only message is rejected with `COMMIT_MESSAGE_REQUIRED` instead of auto-generating one.                                                                                                                |
| `defaultBranchName`  | `string`                                | no       | `'main'`         | Name of the default branch every root is seeded with.                                                                                                                                                                                                                                                                                            |
| `branchProtection`   | `BranchProtectionConfig`                | no       |                  | Branch-protection and approval gates (see below).                                                                                                                                                                                                                                                                                                |
| `mergeStrategy`      | `'fast-forward' \| 'merge-commit'`      | no       | `'fast-forward'` | Default integration strategy for `executeMerge` when a fast-forward is possible. `'fast-forward'` moves the target head with no merge commit; `'merge-commit'` always records an explicit merge commit (git's `--no-ff`). A diverged target always produces a merge commit regardless. Override per call with `executeMerge({ noFastForward })`. |
| `user`               | `CMSUserConfig`                         | no       |                  | Links a user table so reads can enrich with author data.                                                                                                                                                                                                                                                                                         |
| `hooks`              | `{ before?, after? }`                   | no       |                  | Inline before/after hooks on CMS actions.                                                                                                                                                                                                                                                                                                        |
| `schema`             | `{ output?: string }`                   | no       |                  | CLI-only: the `output` path for `createcms generate` (default `./cms-schema.ts`). Not read at runtime.                                                                                                                                                                                                                                           |
| `onRevalidate`       | `RevalidateHandler \| RevalidateConfig` | no       |                  | Called after content changes, for cache revalidation.                                                                                                                                                                                                                                                                                            |
| `onNotification`     | `OnNotificationHandler`                 | no       |                  | Called when the CMS emits a notification.                                                                                                                                                                                                                                                                                                        |
| `onAPIError`         | `(error, request) => void`              | no       | `console.error`  | Called for errors that reach the router: unexpected (non-`APIError`) throws, schema-validation failures, and middleware/auth failures. Attach your own logging or monitoring here. Handler-thrown 4xx `CMSError`s become HTTP responses and do **not** reach this hook. Setting it replaces the default `console.error`.                          |
| `notifications`      | `boolean`                               | no       | `true`           | Set `false` to fully disable notifications — no tables, no routes, and `client.notifications` / `cms.notify` absent from the types (see below).                                                                                                                                                                                                  |
| `realtime`           | `{ url, token }`                        | no       |                  | Upstash Redis credentials. Enables the `/realtime` SSE route, per-user notification push, and A/B live results (see below).                                                                                                                                                                                                                      |

## `media`

`MediaConfig` is a discriminated union on `provider`. These base fields apply to every provider:

| Field                | Type       | Default                                                                                                | Description                                                                                                                                                                                                                                                                                      |
| -------------------- | ---------- | ------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `accessKeyId`        | `string`   |                                                                                                        | Access key ID.                                                                                                                                                                                                                                                                                   |
| `secretAccessKey`    | `string`   |                                                                                                        | Secret access key.                                                                                                                                                                                                                                                                               |
| `sessionToken`       | `string`   |                                                                                                        | Optional token for temporary credentials.                                                                                                                                                                                                                                                        |
| `bucketName`         | `string`   |                                                                                                        | Bucket for stored assets.                                                                                                                                                                                                                                                                        |
| `publicUrl`          | `string`   |                                                                                                        | Public base URL assets are served from.                                                                                                                                                                                                                                                          |
| `maxFileSize`        | `number`   | `4194304` (4 MB)                                                                                       | Maximum upload size in bytes.                                                                                                                                                                                                                                                                    |
| `multipart` | `{ threshold?: number; partSize?: number }` | `{ threshold: 67108864, partSize: 8388608 }` | Files larger than `threshold` bytes (64 MiB) upload in parts of `partSize` bytes (8 MiB) when the storage reports the `multipart` capability; larger parts are used when needed to stay below 9,000 parts. Raise `maxFileSize` for such files to be accepted at all. |
| `maxFiles`           | `number`   | `10`                                                                                                   | Maximum files per upload batch.                                                                                                                                                                                                                                                                  |
| `allowedMimeTypes`   | `string[]` | `['image/png', 'image/jpeg', 'image/webp', 'image/gif', 'video/mp4', 'video/webm', 'application/pdf']` | Allowed MIME types (exact match or a `type/*` wildcard). `image/svg+xml` and `.svg` names are refused whatever the list says. Every upload is sniffed from its first 4,100 bytes: markup (HTML, SVG, XML) is refused under any type except plain text, and image, video, audio and PDF types must match the file's signature. |
| `acl`                | `'public-read' \| false` | `false` | `'public-read'` sends `x-amz-acl: public-read` with uploads, only with `visibility: 'legacy'` and a storage that reports `objectAcl`. |
| `visibility`         | `'prefix' \| 'legacy'` | `'prefix'` | `'prefix'`: keys under `pub/` or `prv/` by status, moved by copy plus delete on status changes; needs the `copy` capability. `'legacy'`: no visibility segment, objects never move. See [Private vs public](/docs/concepts/media#private-vs-public). |
| `onPurge`            | `(paths: string[]) => void \| Promise<void>` | | Called with the gate paths (`/media/asset/<id>`) to purge from a CDN after an object moved, a replace, an archive or a new rendition. Errors are logged. |
| `renditionWidths` | `number[]` | `[320, 640, 1280, 1920]` | Rendition widths. The gate snaps `?w=` up to the next one and rejects a larger `w` with `RENDITION_WIDTH_UNSUPPORTED`. |
| `transform` | `TransformAdapter` | | Image transform service for missing renditions, e.g. `imgproxyTransform({ baseUrl, key, salt })`. The asset endpoint redirects misses of public raster images at an allowed width and format to its signed URL; its widths join `renditionWidths`. See [Transform services](/docs/concepts/media#transform-services). |
| `video` | `VideoConfig` | | `{ provider, minDurationMs?, minBytes? }`: hands public videos at least `minDurationMs` long (default 60 s; without a duration, at least `minBytes`, default 50 MiB) to a streaming provider such as `muxVideo({ tokenId, tokenSecret })` in the pruning pass. See [Video providers](/docs/concepts/media#video-providers). |
| `onRenditionMiss` | `(miss: { assetId, variantKey }) => void \| Promise<void>` | | Called when the gate has no exact or larger rendition and serves the original. Errors are logged. |
| `onAssetDownload` | `(download: { assetIds, actorId, variantKey, bulkJobId, ipHash }) => void \| Promise<void>` | | Called after `downloadIntent` signed downloads, for an audit log. `ipHash` is a SHA-256 prefix of the client address. Errors are logged. |
| `runExport` | `(task: () => Promise<void>) => void` | starts the task unawaited | Runs a `createZipExport` archive in the background, e.g. `(task) => after(task)` in Next.js or `(task) => ctx.waitUntil(task())` on a worker. The pruning pass continues an export a platform stopped early. |
| `downloadRateLimit` | `number` | `60` | Signatures `downloadIntent` hands one actor per minute, counted per server process; `0` turns the limit off. |
| `allowReplaceWithDifferentType` | `boolean` | `true` | `false` rejects a replace whose file has another MIME type than the asset with `INVALID_FILE_TYPE`. |
| `scan` | `ScanAdapter` | | Malware scanner, `{ scan({ assetId, objectKey, mimeType, size, storage }) => 'clean' \| 'infected' \| 'unsupported' }`. With one, new bytes land privately as `processingState: 'pending'`; the pruning pass scans them, makes clean ones `ready` (and public where the asset is) and deletes infected objects (`failed`). Only `ready` assets are delivered (`ASSET_NOT_READY` otherwise) or made public. |
| `onAssetPurge` | `(purge: { assetIds, reason }) => void \| Promise<void>` | | Called after `purgeAssets` erased assets, for an audit log; ids and the reason code only. Errors are logged. |
| `allowedOrigins` | `string[]` | | Origins besides the CMS's own that may call state-changing media endpoints with cookies (an admin UI on another domain). Other cross-site cookie requests answer `ORIGIN_NOT_ALLOWED`. Requests without cookies, and requests sending `x-createcms-media: 1`, are not checked. |
| `quota` | `({ actor, scope }) => { maxBytes?, maxAssets? } \| null` | | Checked when uploads are signed. `maxBytes` counts every stored byte in the scope (originals, renditions, revisions, trash) plus the batch; `maxAssets` counts originals. Exceeding either answers `QUOTA_EXCEEDED`. |
| `uploadRateLimit` | `number` | `60` | Files one actor may sign per minute across `createSignedUpload`, `createSignedReplace` and `createSignedRendition`, counted per server process; `RATE_LIMITED` with `Retry-After` past it. `0` turns the limit off. |
| `preset`             | `StoragePreset` | `'generic'` | `provider: 'custom'` only: the capability preset (`aws`, `r2`, `b2`, `doSpaces`, `hetzner`, `bunny`, `supabase`, `generic`). |
| `capabilities`       | `StorageCapabilitiesOverride` | | Overrides single capability flags of the provider preset. |
| `usageSources` | `MediaUsageSource[]` | `[]` | Usages outside content, each `{ kind, assetsInUse(assetIds) }` returning the ids it uses (asset ids in plugin tables or settings). `archiveAssets` skips such an asset with `external` unless called with `force`; pruning never reclaims it. |
| `externalUsage` | `ExternalUsageRegistry` | | Stores the usages integrations push through `registerExternalUsage`: `{ register({ assetId, consumer, url }), remove({ assetId, consumer, url? }) => removed, list(assetIds) => ExternalUsage[] }`, kept in your own table or service. They show in the `external` group of `getAssetUsages` and only warn on archive (`externalUsages`); unlike `usageSources` they never block archiving or pruning. |
| `guardRichTextReferences` | `boolean` | `true` | Treat an asset id inside a longer string of any block version (rich text HTML, stringified JSON) as a reference: `archiveAssets` skips the asset unless called with `force`, and pruning never reclaims it. |
| `signedUrlExpiresIn` | `number`   | `300`                                                                                                  | Signed URL lifetime in seconds.                                                                                                                                                                                                                                                                  |
| `uploadSecret`       | `string`   |                                                                                                        | HMAC secret for the presign/complete upload tokens. Defaults to a key derived from `secretAccessKey`; set it when using temporary (STS) credentials, since a rotated secret invalidates tokens minted before the rotation.                                                                       |
| `storage`            | `StorageAdapter` |                                                                                                  | Custom storage backend. When set, every storage operation goes through it; `provider` and the credentials are still required by the type but unused for storage I/O. See [Storage adapters](/docs/concepts/media#storage-adapters).                                                              |

Each provider adds its own fields:

- **`provider: 'aws'`**: `region` (required), `forcePathStyle` (default `false`).
- **`provider: 'digitalOcean'`**: `region` (required), `forcePathStyle` (default `true`).
- **`provider: 'cloudflare'`**: `accountId` (required), `jurisdiction`, `forcePathStyle` (default `true`).
- **`provider: 'custom'`**: `hostname` (required), `region` (required), `secure` (default `true`), `forcePathStyle` (default `true`).

```ts
const media = {
  provider: 'cloudflare',
  accountId: process.env.R2_ACCOUNT_ID!,
  bucketName: process.env.R2_BUCKET!,
  accessKeyId: process.env.R2_KEY!,
  secretAccessKey: process.env.R2_SECRET!,
  publicUrl: process.env.R2_PUBLIC_URL!,
};
```

## `authMiddleware`

A function that receives the request context and returns a result object. `userId` is optional (anonymous requests omit it); any extra fields you return extend the context available to scoping and hooks.

`authMiddleware` is **required** — `createCMS` throws at construction without it, so auth is never silently absent. To run public/dev with no auth on purpose, pass `allowAnonymous()` (exported from `@createcms/core`), which authorizes every request; see [Security → Authentication is required](/docs/resources/security#authentication-is-required).

```ts
import { defineAuthMiddleware } from '@createcms/core';

const authMiddleware = defineAuthMiddleware(async (ctx) => {
  // ctx.operation, ctx.request (a curated request; the raw Request is at
  // ctx.request?.request), and ctx.collection (collection-scoped calls only).
  return { userId: await resolveUser(ctx) };
});
```

## `realtime`

Enables live server-to-client delivery — notification push and A/B live results — over Server-Sent Events. **Upstash-only**: pass your Upstash Redis credentials. `@upstash/realtime` and `@upstash/redis` are optional peer dependencies. See [Realtime](/docs/concepts/realtime).

```ts
const realtime = {
  url: process.env.UPSTASH_REDIS_REST_URL!,
  token: process.env.UPSTASH_REDIS_REST_TOKEN!,
};
```

Requires `authMiddleware` to resolve the user from the request **cookie** — the realtime route authenticates each connection by session, so it must be same-origin with your app. Omit `realtime` to disable; notifications stay available through the `notifications.list` poll.

## `notifications`

Set `false` to fully disable the notifications feature. When disabled, the notification tables are not generated (regenerate your schema after toggling), the routes never register, and `client.notifications` plus `cms.notify` are **absent from the inferred types**. Default: enabled. Use a literal `false` — a widened `boolean` keeps the types enabled. Independent of `realtime`.

```ts
const cms = createCMS({ /* … */ notifications: false });
```

## `dataRetention`

The whole object is optional, but when you provide it, `keepDays` and `keepMinCommits` are required.

| Field             | Type     | Required | Default    | Description                                           |
| ----------------- | -------- | -------- | ---------- | ----------------------------------------------------- |
| `keepDays`        | `number` | yes      |            | How long to keep old commits.                         |
| `keepMinCommits`  | `number` | yes      |            | Minimum commits to keep per branch regardless of age. |
| `archiveKeepDays` | `number` | no       | `keepDays` | Grace period before an archived root is hard-deleted. |

## `branchProtection`

Governance for published content and the merge/publish approval gates. Every field is opt-in; an empty config preserves current behavior. Each field can be **overridden per collection** via the collection's own `branchProtection` (a `Partial<BranchProtectionConfig>`): a collection's value wins over this global one field-by-field, and unset fields inherit the global value. For example a `reusableBlock` collection can set `branchProtection: { protectPublishedBranches: false }` to stay directly editable while pages keep the global protection.

| Field                          | Type      | Default | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ------------------------------ | --------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `protectPublishedBranches`     | `boolean` | `false` | Lock a branch against direct content mutations (create/update/delete/move/duplicate of blocks, `updateRoot`, and reverting the branch) for exactly as long as it is **published** — the live tree is immutable in place. Changes go via another branch + merge, then a re-publish; unpublishing makes the branch directly editable again. Applies to **any** published branch (a root can have several at once, e.g. A/B variants), not just the default one. A never-published branch is freely editable. Throws `PROTECTED_BRANCH`. |
| `requireApprovalToMerge`       | `boolean` | `false` | Require approvals before `executeMerge`. **Note:** previously merges always required approval — this now defaults to off; set `true` to keep the gate.                                                                                                                                                                                                                                                                                                                                                                                |
| `requireApprovalBeforePublish` | `boolean` | `false` | Require approvals before `publishBranch`, even when none were explicitly requested. `false` keeps the existing conditional behavior (gate only when approvals exist).                                                                                                                                                                                                                                                                                                                                                                 |
| `dismissStaleApprovals`        | `boolean` | `false` | Whether pushing new commits to a merge request's source branch invalidates existing approvals. `false` keeps GitHub's default pull-request behavior (an approval survives a subsequent push). Set `true` for GitHub's "Dismiss stale pull request approvals when new commits are pushed": `executeMerge` then only counts approvals recorded against the source branch's current head commit, and a superseded approval fails with `APPROVALS_STALE`.                                                                                 |
| `requiredReviewers`            | `number`  | `1`     | Minimum distinct approved reviewers for the merge / publish gates, on top of "all requested reviewers approved".                                                                                                                                                                                                                                                                                                                                                                                                                      |

## `mergeStrategy`

The default integration strategy for [`executeMerge`](/docs/reference/server-api), applied when a fast-forward is possible — that is, when the target branch has not diverged from the merge base.

| Value            | Behavior                                                                                                  |
| ---------------- | --------------------------------------------------------------------------------------------------------- |
| `'fast-forward'` | Move the target head straight to the source head, with no merge commit. The default.                      |
| `'merge-commit'` | Always record an explicit merge commit — git's `--no-ff` — so every integration stays visible in history. |

A **diverged** target always produces a merge commit regardless of this setting, and a merge with nothing to integrate is always a no-op fast-forward. Override the configured strategy per call with `executeMerge({ noFastForward })`: `true` forces a merge commit, `false` forces a fast-forward. See [Merges](/docs/concepts/merges#fast-forward-vs-merge-commit).

## `user`

| Field           | Type                                        | Description                                                                                          |
| --------------- | ------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| `table`         | `AnyPgTable`                                | Your Drizzle user table.                                                                             |
| `idColumn`      | `AnyColumn`                                 | The user id column referenced by content.                                                            |
| `exposeColumns` | `(keyof TTable['$inferSelect'] & string)[]` | Allowlist of user-table columns (camelCase keys) that may be returned via the `withUser` query flag. |

## Return value

`createCMS` returns:

| Property              | Description                                                                                         |
| --------------------- | --------------------------------------------------------------------------------------------------- |
| `router`              | HTTP router; destructure `handler` to mount it.                                                     |
| `api`                 | Type-safe server-side callers, namespaced by collection (and `admin`).                              |
| `collections`         | Your collections, each augmented with its `name`.                                                   |
| `notify`              | Send a notification through the CMS.                                                                |
| `notificationService` | The underlying notification service.                                                                |
| `revalidate`          | Manual revalidation trigger. Always present; its value is `undefined` unless `onRevalidate` is set. |
| `$ERROR_CODES`        | Merged error-code map (core plus plugins).                                                          |
