title: Media
description: Unstyled parts, hooks, and types for @createcms/react/media.

The headless media library: a framework-free store with slices, typed
events, commands and extension registries (`@createcms/react/media/core`,
see [Media core](/docs/reference/react-media-core)), and unstyled parts that
bind to it. Every part renders one element with `data-*` state and ARIA
built in, and accepts a `render` prop; styling happens in your wrappers (the
`media-library` registry item is one).

```ts
import { Bulk, Filter, Folder, Intake, Media, Selection } from '@createcms/react/media';
```

## Usage

```tsx
import { Bulk, Filter, Folder, Intake, Media, Selection } from '@createcms/react/media';
import { createHistoryFilterAdapter } from '@createcms/react/media/core';

import { cmsClient } from './cms-client';

const filterUrl = createHistoryFilterAdapter();

function MediaLibrary() {
  return (
    <Media.Root client={cmsClient.media} selection="multiple" filterUrl={filterUrl}>
      <Folder.Tree>{(row) => <Folder.Item row={row}>{row.name}<Folder.Rename /></Folder.Item>}</Folder.Tree>
      <Media.Breadcrumbs>
        {({ head, overflow, tail }) =>
          [...head, ...overflow, ...tail].map((folder) => <Media.Crumb key={folder.id} folder={folder} />)
        }
      </Media.Breadcrumbs>
      <Media.Search />
      <Filter.Chip dimension="kinds" value="image" />
      <Intake.Dropzone>
        <Intake.Input />
        <Intake.FolderInput />
      </Intake.Dropzone>
      <Media.Grid style={{ minHeight: 400 }} renderUpload={(entry) => <Media.UploadTile key={entry.id}><Media.UploadPreview /></Media.UploadTile>}>
        {(asset) => (
          <Media.Item key={asset.id} asset={asset}>
            <Selection.Checkbox />
            <Media.Thumbnail />
            {asset.originalName}
          </Media.Item>
        )}
      </Media.Grid>
      <Media.Empty />
      <Media.LoadMore />
      <Selection.Bar>
        <Selection.Count />
        <Selection.SelectAllMatching />
        <Bulk.Bar>{(actions) => actions.map(({ action }) => <Bulk.Action key={action.id} action={action.id} />)}</Bulk.Bar>
      </Selection.Bar>
      <Bulk.Outcome>{({ message, undo }) => <p>{message}{undo ? <button onClick={undo}>Undo</button> : null}</p>}</Bulk.Outcome>
      <Intake.Overlay />
    </Media.Root>
  );
}
```

`client` is read once at mount: `Media.Root` calls `client.useUploadAssets()`
as a hook on every render. Render with a different `key` to swap clients.

## Client shape

`MediaClient` duck-types the `media` surface of the React client with the
live proxy envelope (`{ query }`, `{ body }`); `cmsClient.media` fits it
without glue code. Required: `listAssets`, `listFolders`, `createFolder`,
`moveAssets`, `archiveAssets`, `updateAssetsStatus` and the
`useUploadAssets()` hook (a `MediaUploadState`). Optional, used by the parts
that need them: `getAssets`, `getAssetFacets`, `updateAsset`,
`restoreAssets`, `renameFolder`, `moveFolder`, `getFolderPath`,
`deleteFolder`, `getAssetUsages`, `getAssetUsageCounts`, `listRevisions`,
`setCurrentRevision`, `setFocalPoint`, `downloadIntent`, `purgeAssets`,
`createSignedReplace`, `commitReplace` and `subscribe(onEvent)`, which feeds
`MediaServerEvent`s (the `media.*` realtime events) to the store.

| Type | Meaning |
| --- | --- |
| `MediaAsset` | One listed asset (`AssetListItem` of the server). |
| `MediaFolderRecord` | One folder: `{ id, name, parentId, folderCount?, assetCount?, assetCountRecursive? }`. |
| `MediaAssetListQuery`, `MediaAssetFilterQuery` | The `listAssets` query and its filter part (lists comma separated). |
| `MediaAssetListResult` | `{ assets, total, hasMore, nextCursor }`; `total` is `null` with `includeTotal: false`. |
| `MediaBulkTarget`, `MediaAllMatching` | A bulk body: `assetIds`, or `allMatching: { query, except }` resolved on the server. |
| `MediaFacets` | `{ kinds, provenance, visibility }` counts of `getAssetFacets`. |
| `MediaServerEvent` | `{ type: 'media.asset.updated', assetId }` and the other `media.*` events. |
| `MediaAssetStatus`, `MediaSortBy`, `MediaSortDirection`, `MediaSelectionMode` | `'private' \| 'public'`, the sort keys, `'asc' \| 'desc'`, `'none' \| 'single' \| 'multiple'`. |
| `MediaUploadState`, `MediaUploadEntry`, `MediaUploadedAsset` | The upload queue state, one entry, and the `result` of a finished entry. An entry carries `assetId` once its upload is signed. |
| `MediaRevision` | One earlier version of an asset (`listRevisions`): `{ id, originalName, mimeType, size, width, height, note, uploadedBy, createdAt }`. |

## Parts

### `Media.Root`

Provider-only (`MediaRootProps`): renders the live regions and no other DOM.
It creates the store (or uses `store`), opens the start folder, hands the
client's `upload` to the store, inserts finished uploads into the collection
without a reload, syncs the filter with `filterUrl` (read after mount, so
server and client render the same markup; back and forward restore it) and
announces upload progress, selection changes and results.

```ts
type MediaRootProps = {
  client: MediaClient; // read once at mount
  store?: MediaStore; // created outside, e.g. shared with a picker; not disposed by the root
  defaultFolderId?: string | null; // read once; null = root level
  filterUrl?: FilterUrlAdapter; // createHistoryFilterAdapter() or createMemoryFilterAdapter()
  selection?: MediaSelectionMode; // read once
  keepHiddenSelection?: boolean; // keep selected ids a filter hides
  pageSize?: number; // 1-100, default 40
  layout?: 'grid' | 'justified' | 'masonry' | 'list';
  expandedStorageKey?: string | false; // localStorage key of the expanded folders
  onSelectionChange?: (ids: string[]) => void;
  assetUrl?: (asset: MediaAsset) => string; // thumbnail fallback, default asset.deliveryUrl
  announce?: Announce; // speak through another live region (the editor's)
  messages?: MediaMessagesInput;
  locale?: string;
  children?: ReactNode;
};
```

Announcements are polite except when every file of an upload batch failed. A
batch announces its start, at most five progress steps (25, 50 and 75
percent or every 10 seconds, a jump over several thresholds once) and its
result ("11 of 12 files uploaded, 1 failed"); selection changes settle for
400 ms before "4 selected", "All 312 selected" or "Selection cleared" is
spoken.

### `Media.Grid` and `Media.Item`

`Media.Grid` (`MediaGridProps`) is an APG grid: `role="grid"` with
`role="row"` elements (`aria-rowindex`) and `gridcell` items
(`aria-colindex`), `aria-multiselectable` in multiple mode, `aria-rowcount`
(`-1` while more pages exist) and `aria-colcount`. The layout engine places
every cell absolutely from the stored dimensions (`layout` mode of the store:
`grid` with `minCell`, `gap` and `aspect`, `justified` with
`targetRowHeight`, `masonry`, `list` with `listRowHeight`); the grid gets the
content height. From `virtualizeFrom` items (200) only the rows in view plus
`overscan` (2) are mounted, measured against the nearest scrolling ancestor;
the focused item always stays mounted. State: `data-status`
(`idle`, `loading`, `refreshing`, `appending`, `error`), `data-layout`,
`data-empty`, `data-virtualized`.

| Key | Action |
| --- | --- |
| Arrows | Move the focus along the layout (up and down keep the column, the lane or the closest center); RTL mirrors left and right. |
| Shift+Arrow | Extends the selection from the anchor. |
| Cmd/Ctrl+Arrow | Moves the focus without selecting. |
| Space | Toggles the focused item. Alt+Space opens the preview. |
| Cmd/Ctrl+A | Selects every loaded item. |
| Home, End | Start or end of the row; with Cmd/Ctrl the first or last item. |
| Page Up, Page Down | As many rows as fit the viewport. |
| Enter, double click | Calls `onAction(asset)`. |
| Escape | Clears the selection. |
| Letters | Type-ahead over the file names (500 ms buffer). |

A press on empty space starts a marquee after 6 px (pointer only, multiple
mode): it hit-tests the layout rects, so items outside the mounted window are
selected too, scrolls in an edge band of `min(25%, 180 px)` that ramps up over
400 ms, and announces the count when released. Shift adds, Cmd/Ctrl toggles.
`Media.Marquee` (`MediaMarqueeProps`) renders the band while it runs.

`Media.Item` (`MediaItemProps`, `asset` required) is the `gridcell`: its
name is the file name (`assetName(asset)`), its description the type,
dimensions and size. A click replaces the selection, Cmd/Ctrl-click toggles,
Shift-click replaces the previous range from the anchor (Finder), Shift with
Cmd/Ctrl adds a range. On touch, a long press (500 ms, cancelled by more
than 10 px of movement so scrolling never selects) toggles the item into
the selection with a short vibration where available. State: `data-selected`, `data-focused`,
`data-asset-status`, `data-type` (`MediaType` from `mediaTypeOf`),
`data-provenance` and `data-processing-state` (`pending` while the malware
scan runs, `failed` after it found malware; label them with
`messages.processing`). It provides `ItemContextValue` (`{ asset, selected }`)
through `useMediaItemContext(name)`. Items are draggable (see
[Drag and drop](#drag-and-drop)).

### `Media.Thumbnail`

`MediaThumbnailProps`: the smallest WebP rendition of at least `width`
(320) through the asset endpoint, a `srcset` of the existing renditions only
and `sizes` from the cell; without renditions the root's `assetUrl` (the gate
path, never a private bucket URL). `width` and `height` come from the asset;
the rows in the first viewport load eagerly, the rest lazily, and
`decoding="async"`. The ThumbHash (`placeholderDataUrl`) or the dominant
colour is the background until `data-loaded`. `alt` is empty: the cell is
named. Non-image assets render `fallback`.

### `Media.UploadTile` and `Media.UploadPreview`

With `renderUpload`, uploads in flight to the open folder show first in the
grid. `Media.UploadTile` (`MediaUploadTileProps`) is their `gridcell`, named
"hero.png, uploading 45%", with `data-status`; it is replaced by the asset
once the upload finished. `Media.UploadPreview` (`MediaUploadPreviewProps`)
shows the local file through `URL.createObjectURL`, revoked once it loaded.

### `Media.Breadcrumbs` and `Media.Crumb`

`Media.Breadcrumbs` (`MediaBreadcrumbsProps`) is a `nav` labelled
`folder.path`; `children` receives a `BreadcrumbPath`
(`{ head, overflow, tail, all }`): from `collapseFrom` folders (4) the middle
goes to `overflow` for a menu. A start folder opened by id gets its full path
from `getFolderPath`. `Media.Crumb` (`MediaCrumbProps`, `folder`, `null` =
root) is a `button` with `aria-current="page"` on the open folder, and a drop
target: assets dropped on it move there, a drag hovering 500 ms opens it.

### `Media.FolderList` and `Media.Folder`

`Media.FolderList` (`MediaFolderListProps`) lists the subfolders of the open
folder as a `ul`. `Media.Folder` (`MediaFolderProps`) is a `button` that
opens one; it is a drop target for assets, folders and OS files
(`data-drop-over`, `data-drop-flash`) and draggable onto another folder.

### `Media.Search`, `Media.LoadMore`, `Media.Empty`

`Media.Search` (`MediaSearchProps`) is an `input[type="search"]` for the
filter's `q`: the store reloads 250 ms after typing stops and the URL is
replaced, not pushed; Escape clears it. `Media.LoadMore`
(`MediaLoadMoreProps`) appends the next page and announces "40 more assets
loaded, 120 of 312"; it renders only while a next page exists (`aria-busy`
while loading). Loading is a button by default; `Media.Grid autoLoad` loads
when the end is a viewport away. `Media.Empty` (`MediaEmptyProps`) renders
only for an empty collection, with `data-empty-reason`: `folder-empty`,
`no-results`, `error` or `no-permission`, and the catalog text by default.

### `Media.Error` and `Media.MutationError`

Both are `div[role="alert"]`. `Media.Error` (`MediaErrorProps`) renders on
a failed list request with `children({ error, retry })`.
`Media.MutationError` (`MediaMutationErrorProps`) renders on a rejected bulk
change with `children({ error, dismiss })`. Optimistic changes are rolled back
before either shows.

### `Selection.*`

| Part | Element | Description |
| --- | --- | --- |
| `Selection.Checkbox` (`SelectionCheckboxProps`) | `input[type=checkbox]` | Inside `Media.Item`: always visible in selection modes, toggles without replacing (touch, discoverability). Not a tab stop. |
| `Selection.Count` (`SelectionCountProps`) | `span` | "4 selected" or "All 312 selected". |
| `Selection.Bar` (`SelectionBarProps`) | `div` | Shown while something is selected; `data-count`. |
| `Selection.SelectAllMatching` (`SelectionSelectAllMatchingProps`) | `button` | "Select all 312": every asset of the current filter on the server, loaded or not; shown only when more match than are loaded. Bulk actions then send `allMatching`. |
| `Selection.Hidden` (`SelectionHiddenProps`) | `p` | "3 selected items are hidden by filters" (with `keepHiddenSelection`). |
| `Selection.Clear` (`SelectionClearProps`) | `button` | Clears the selection. |

### `Bulk.*`

Bulk actions come from the store's action registry
(`store.registries.assetActions`): built-ins `move`, `makePublic`,
`makePrivate`, `setProvenance`, `download`, `archive`, `restore`, plus your
own (`{ id, label, canExecute, confirm?, run }`, see `BulkAction` in
[Media core](/docs/reference/react-media-core)).

| Part | Element | Description |
| --- | --- | --- |
| `Bulk.Bar` (`BulkBarProps`) | `div[role=toolbar]` | `children(actions)` with every `BulkActionItem` (`{ action, enabled, label }`); shown while something is selected. |
| `Bulk.Action` (`BulkActionProps`) | `button` | Runs one action (`action` id) with `input` (`{ folderId }` for `move`). Disabled actions keep focus: `aria-disabled`, `data-disabled-reason` and a `title` from `bulk.disabled`. `confirm(descriptor)` is asked first where the action has a confirmation, and again with the assets an archive skipped because they are in use (`archiveInUse`), to archive them with `force`. After a removal the focus moves to the next item. |
| `Bulk.Outcome` (`BulkOutcomeProps`) | `div` | The last result as a toast, `children({ message, undo, dismiss })`; `undo` where the change is invertible ("4 assets moved to Products. Undo"). Hidden after `timeout` (8 s). `BulkOutcome` is its data. |

### `Folder.*`

| Part | Element | Description |
| --- | --- | --- |
| `Folder.Tree` (`FolderTreeProps`) | `ul[role=tree]` | The folder tree with lazy children: opening a node lists them (`aria-busy` meanwhile), the expanded set persists in `localStorage`. Up/Down, Right opens or enters, Left closes or goes up, Home/End, `*` opens the siblings, type-ahead; F2 or Enter renames and Space opens. `mode="pick"` with `value`, `onValueChange` and `onConfirm` chooses a target (the "Move to" dialog). |
| `Folder.Item` (`FolderItemProps`) | `li[role=treeitem]` | One row: `aria-level`, `aria-setsize`, `aria-posinset`, `aria-expanded`, `aria-current`. Drop target (hovering 500 ms opens a closed node) and draggable. State: `data-current`, `data-expanded`, `data-loading`, `data-picked`, `data-renaming`, `data-drop-over`. |
| `Folder.Toggle` (`FolderToggleProps`) | `span` | The decorative disclosure; a click toggles. |
| `Folder.Rename` (`FolderRenameProps`) | `input` | The inline rename field while the item is renamed. |
| `Folder.Create` (`FolderCreateProps`) | `input` | Creates a folder inline: prefilled and selected "New folder", Enter creates, Escape cancels, `onDone(folder)`; announces "Folder created: name". |
| `Folder.NameInput` (`FolderNameInputProps`) | `input` | The field both use: a conflict (`FOLDER_NAME_TAKEN`) stays inline as `aria-invalid`. |

`useFolderTree()` returns `{ rows, currentId, path, expand, collapse, open }`
with `FolderTreeState`-style rows (`FolderTreeRow`: level, set size, position,
expanded, loading). `useFolderDelete(folder)` returns `FolderDeleteState`:
a dry-run `FolderDeletePreview` (`{ folders, assets, assetsInUse, pages }`),
`requireTyping` (the folder name when used assets are affected) and
`confirm(mode, typed)` with the modes `empty-only`, `move-to-parent` and
`archive-contents`.

### `Filter.*`

`Filter.Chip` (`FilterChipProps`) is a toggle `button` (`aria-pressed`) for
one filter value (`dimension`: `kinds`, `provenance`, `visibility`, `usage`,
`missingAlt`) labelled from `filter.*` with its count from `facets`;
toggling pushes a history entry. `Filter.Clear` (`FilterClearProps`) keeps
folder and sort and drops the rest. `Filter.Scope` (`FilterScopeProps`)
shows "Searching in Products" while searching inside a folder, with a switch
to search every folder.

### `Intake.*`

| Part | Element | Description |
| --- | --- | --- |
| `Intake.Dropzone` (`IntakeDropzoneProps`) | `div` | Drop area for OS files and folders: `data-drag-over` is `window` while files are dragged over the page and `zone` over it, `data-drag-accept` says whether they fit (count, and types in Chromium, before the drop). Drops during uploads are queued. |
| `Intake.Overlay` (`IntakeOverlayProps`) | `div` | Full-window drop target while OS files are dragged over the page (an enter/leave counter keeps it from flickering). |
| `Intake.Input` (`IntakeInputProps`) | `button` | Opens the file picker ("Upload files"); `capture` opens the camera on mobile. |
| `Intake.FolderInput` | `button` | Opens a folder picker ("Upload folder", `webkitdirectory`). |
| `Intake.Camera` (`IntakeCameraProps`) | `button` | Opens the device camera (`kind`: `photo` or `video`, `facing`: `environment` or `user`) and uploads the shot; browsers without a camera show their file picker. |
| `Intake.Paste` (`IntakePasteProps`) | `button` | Reads images from the clipboard (`navigator.clipboard.read`); rendered only where available. |
| `Intake.FolderPrompt` (`IntakeFolderPromptProps`) | none | `children(prompt)` while a folder drop asks "Recreate the folder structure (12 folders, 340 files)" or "Put everything in the current folder" (`IntakeFolderPromptState`). |
| `Intake.Reading` (`IntakeReadingProps`) | `div[role=status]` | "Reading folder… 340 files" while a dropped folder is traversed. |

All take `IntakeHandlerOptions`: `accept`, `maxSize`, `maxFiles`, `minWidth`
and the other `IntakeConstraints`, `folderId`, `intake` limits (500 files,
10 levels, total bytes), `onUploaded(entries)` and `onRejected(file,
reason)`. System files (`.DS_Store`, `Thumbs.db`, dot files, `__MACOSX/`)
are skipped and counted. `useIntake(options)` returns the `IntakeHandler`
(`{ reading, prompt, receive, receiveDrop }`) for your own sources;
`useIntakePaste(target, options)` uploads pasted files while `target` (an
element ref or `'document'`) has the paste, renaming screenshots to
`pasted-YYYY-MM-DD-HHmmss.png` and leaving text fields alone.

### `Upload.*`

The upload panel of `Media.Root`'s client. Inside an `Upload.Item` the
actions act on that entry and are labelled with its name; outside one they
act on the whole queue.

| Part | Element | Description |
| --- | --- | --- |
| `Upload.List` (`UploadListProps`) | `ul` | The queue (rendition entries are part of their parent); `children(entry)` renders one entry. |
| `Upload.Item` (`UploadItemProps`, `entry` required) | `li` | `data-status`, and `data-duplicate` while the entry waits for a duplicate decision. |
| `Upload.Progress` (`UploadProgressProps`) | `div[role=progressbar]` | `aria-valuenow` in 10 percent steps, `aria-valuetext` with the exact value (`45%`, `Failed: <message>`, `Cancelled`), `aria-label` the file name; outside an item the whole queue (`upload.all`). |
| `Upload.Cancel` (`UploadCancelProps`) | `button` | Cancels the entry, or every upload in flight; `disabled` when nothing runs. |
| `Upload.Retry` (`UploadRetryProps`) | `button` | Retries a failed or cancelled entry. |
| `Upload.RetryAll` (`UploadRetryAllProps`) | `button` | Retries every failed entry; `disabled` while none failed. |
| `Upload.Pause` (`UploadPauseProps`) | `button` | Pauses the entry (or the queue) and resumes it when paused. |
| `Upload.Clear` (`UploadClearProps`) | `button` | Clears the ledger; `disabled` while uploads run or nothing is listed. |
| `Upload.Duplicate` (`UploadDuplicateProps`) | none | Inside an item waiting for a duplicate decision: `children(UploadDuplicateRenderProps)` with `existing`, `keepExisting(assetId?)` and `uploadAnyway()`. |

`useUploadEntry()` returns the entry of the enclosing `Upload.Item`.
`isUploadActive(entry)` and `isUploadDuplicate(entry)` classify entries.
`useUploadsPending(assetIds)` returns the entries of those asset ids still
in flight: a form stores `entry.assetId` as soon as the upload is signed
and waits for this list to be empty before it saves (`upload.waiting`).

### `Download.*`

`Download.Button` (`DownloadButtonProps`: `assets`, `name`) downloads one
asset through the asset endpoint (`?download=true`) and several as one ZIP
archive. Archives are written in the browser: files are signed in batches
through `downloadIntent`, fetched three at a time and stored uncompressed
into the archive, which streams to a file the user picks where the browser
can (`showSaveFilePicker`) and is assembled in memory up to 2 GB otherwise
(500 MB on iOS). The bulk `download` action uses the same queue for more
than one asset.

`Download.List` (`DownloadListProps`) is a `ul` of the jobs with
`children(job)`; `Download.Item` (`DownloadItemProps`, `job` required) a
`li` with `data-status`; `Download.Progress` (`DownloadProgressProps`) a
progress bar of the archive's bytes, exact because nothing is compressed;
`Download.Cancel` (`DownloadCancelProps`) cancels the job or every running
one. `useDownloads()` returns `MediaDownloads`: the jobs, `supported`
(`false` without `downloadIntent`), `download(assets, options)`, `cancel`
and `clear`.

### `Preview.*`

`Preview.Root` (`PreviewRootProps`) is a modal `div[role="dialog"]`
rendered while an asset is open (`usePreview().open(id)`, usually from
`Media.Grid`'s `onAction`). It moves focus into the dialog, traps Tab,
returns focus to the opener and maps keys: Escape closes, the arrows step
(mirrored in right-to-left layouts, panning instead while zoomed), `+`,
`-` and `0` zoom, `r` rotates. Neighbouring images are preloaded. Stepping
follows the collection order at the time the preview opened and stops at
both ends.

`Preview.Stage` (`PreviewStageProps`) renders the asset by kind: images
and SVG as `img` (double click toggles between fit and natural size, drag
pans while zoomed, a swipe steps or closes on touch), video and audio with
native controls, PDF in an `object`, anything else as
`preview.unavailable`. `children({ asset, kind, src })` replaces the
renderer for a kind; return `undefined` to keep the default.

`Preview.Prev`, `Preview.Next`, `Preview.Close`, `Preview.ZoomIn`,
`Preview.ZoomOut`, `Preview.ZoomReset` and `Preview.Rotate` are buttons
(`PreviewButtonProps`) labelled from `preview.*` and disabled where they do
nothing. `Preview.Position` (`PreviewPositionProps`) reads "3 of 40".
`usePreview()` returns `MediaPreview`: `asset`, `kind`, `index`, `total`,
`zoom`, `pan`, `rotation`, `canPrev`, `canNext` and the commands.

### `Detail.*`

The detail form of one asset: file name, description, rights, origin, facts
and versions. Alt text is not part of it; it belongs to each use of the
image (`ImageField.*`).

| Part | Element | Description |
| --- | --- | --- |
| `Detail.Root` (`DetailRootProps`) | `form` | Rendered while an asset is open (`useAssetDetail().open(id)`); submitting saves. `data-dirty`, `data-saving`, `data-conflict`. |
| `Detail.Field` (`DetailFieldProps`, `field` required) | `input` | One field of the draft: `originalName`, `description`, `rights.credit`, `rights.copyright`, `rights.license`, `rights.licenseUrl`, `rights.sourceUrl`, `rights.expiresAt` or `custom.<key>`. Render a `textarea` through `render`. |
| `Detail.Provenance` (`DetailProvenanceProps`) | `select` | The origin, labelled from `filter.provenance`. |
| `Detail.Facts` (`DetailFactsProps`) | `dl` | Type, size, dimensions, upload and change dates, uploader; `children(facts)` replaces the list. |
| `Detail.Save` (`DetailSaveProps`) | `button[type=submit]` | `disabled` without changes or while saving. |
| `Detail.Reset` (`DetailResetProps`) | `button` | Discards the draft. |
| `Detail.Error` (`DetailErrorProps`) | `p[role=alert]` | The translated error of the last save, except conflicts. |
| `Detail.Conflict` (`DetailConflictProps`) | none | While a save conflicts: `children({ theirs, keepMine, takeTheirs })`. |
| `Detail.Revisions` (`DetailRevisionsProps`) | none | Loads the earlier versions on mount: `children({ revisions, restore })`. |

Saving sends only the changed fields with `expectedUpdatedAt`; an
`ASSET_CONFLICT` keeps the draft and offers to save it over the newer
version or to take that version. `useAssetDetail()` returns `AssetDetail`:
`asset`, `values`, `draft`, `facts`, `dirty`, `saving`, `error`,
`conflict`, `revisions` and the commands (`open`, `close`, `set`,
`reset`, `save`, `resolveConflict`, `loadRevisions`, `restoreRevision`).

### `FocalPoint.*` and `Crop.*`

`FocalPoint.Root` (`FocalPointRootProps`: `image`, `value` or
`defaultValue`, `onValueChange`, `onValueCommit`) is a `div` on which a
click or drag places the focal point. `FocalPoint.Handle`
(`FocalPointHandleProps`) is the marker as a focusable `role="slider"`:
arrows move it 1 percent, with Shift 10 percent, Home centers it, and
`aria-valuetext` reads "42% from the left, 30% from the top".
`FocalPoint.Preview` (`FocalPointPreviewProps`) is the image cropped with
`object-fit: cover` at the point; render several with different aspect
ratios. Save on `onValueCommit` with the `setFocalPoint` command. The image
is an `EditableImage`: `{ src, width, height }`.

`Crop.Root` (`CropRootProps`: `image`, `value`, `onValueChange`,
`presets`, `defaultAspect`, `focal`) holds the crop of one image use in
fractions of the original; it is stored in the reference, never in the
asset, so every use keeps its own. `onValueChange` receives `null` for the
whole image. `Crop.Area` (`CropAreaProps`) shows the image with the crop
box (`data-crop-box`), moved by drag or arrows; `Crop.Zoom`
(`CropZoomProps`) is a range from 1 to 3; `Crop.Aspect` (`CropAspectProps`)
a radio group of `free`, `original` and the presets, each choice setting
the largest crop around the focal point; `Crop.Input` (`CropInputProps`,
`field`: `x`, `y`, `width` or `height`) edits one value in pixels;
`Crop.Reset` (`CropResetProps`) returns to the whole image; `Crop.Preview`
(`CropPreviewProps`) shows the result. `useCropEditor()` returns the state
with `tooSmall`, true while the crop is narrower than the preset's
`minWidth`.

### `ImageField.*`

The alt text, decorative switch and caption of one use of an image, stored
in the reference (`AssetRef`). `ImageField.Root` (`ImageFieldRootProps`:
`value`, `onValueChange`, `requireAlt`, `suggesters`, `context`) renders no
element.

| Part | Element | Description |
| --- | --- | --- |
| `ImageField.Alt` (`ImageFieldAltProps`) | `textarea` | Typing marks the text as the person's (`altSource: 'user'`); `disabled` while decorative, `aria-invalid` while required and missing. |
| `ImageField.Decorative` (`ImageFieldDecorativeProps`) | `input[type=checkbox]` | Decorative images render `alt=""`; the typed text is kept. |
| `ImageField.Caption` (`ImageFieldCaptionProps`) | `input` | The visible caption. |
| `ImageField.SuggestAlt` (`ImageFieldSuggestAltProps`) | `button` | Asks the `suggesters` in order. A suggestion only fills an empty, non-decorative field and is marked `ai-suggested`. |
| `ImageField.Status` (`ImageFieldStatusProps`) | `p` | `imageField.missingAlt` or `imageField.suggested`; nothing otherwise. `data-alt-state`. |

`useImageField()` returns `ImageFieldState`: `value`, `altState`, `valid`,
`suggesting`, `canSuggest`, `onValueChange` and `suggest()`.

### `Picker.*` and `openMediaPicker`

`Picker.Root` (`PickerRootProps`, `constraints` required) applies
`PickerConstraints` to the `Media.Root` it sits in. Pass
`pickerFilter(constraints)` to the root's filter and
`intakeConstraintsOf(constraints)` to its uploads, so the listing, the
uploads and the choice follow the same rules. `Picker.Reason`
(`PickerReasonProps`) inside `Media.Item` shows why the asset is locked
("Needs at least 1,200 × 630 px"); `usePickerItem(asset)` returns
`{ disabled, reason, text }` for `aria-disabled` and styling, and
`pickerReasonText(reason, constraints, catalog)` translates a reason
yourself. `Picker.Confirm` (`PickerConfirmProps`, `onConfirm(assets)`) is
`disabled` until the choice meets `min` and `max` and every chosen asset
passes. `usePickerConstraints()` reads the constraints.

`openMediaPicker(constraints)` resolves with the chosen assets, or `null`
when cancelled, from anywhere: a field control, a canvas drop target, a
toolbar button. It needs one mounted `MediaPickerHost`
(`MediaPickerHostProps`), whose `children(request)` renders the picker for
a `MediaPickerRequest` (`{ constraints, resolve, cancel }`).

### `Media.Image` and `Media.Picture`

Render an asset (`ImageAsset`: an `AssetListItem` with `variants`) as a
responsive image. They work outside `Media.Root`, e.g. on public pages.
`Media.Image` (`MediaImageProps`) is an `<img>` whose `srcset` lists the
asset's **existing** WebP renditions only, never a guessed width;
`Media.Picture` wraps the same `<img>` in a `<picture>` with one `<source>`
per format that has renditions (AVIF, then WebP).

```tsx
<Media.Image
  asset={asset}
  alt={ref.alt ?? ''}
  sizes="(min-width: 768px) 50vw, 100vw"
  focal={ref.focal}
  placeholderDataUrl={placeholderDataUrl} // from '@createcms/core'
/>
```

`alt` is required (`""` for a decorative image). `width` and `height` come
from the asset, `loading` defaults to `lazy` and `decoding` to `async`. The
focal point (`metadata.focal`, overridden by `focal`) becomes
`object-position`; with `object-fit: cover` the crop keeps it in view. Until
the image loads, the ThumbHash placeholder (with `placeholderDataUrl`) or the
dominant colour is its background.

| Data attribute | Value |
| --- | --- |
| `data-provenance` | `unknown`, `captured`, `ai_generated` or `ai_edited` |
| `data-loaded` | Present once the image loaded |
| `data-placeholder` | Present while the placeholder shows |
| `data-variant-missing` | The expected variant keys (`widths` below the source width) that do not exist |

The same data is available without React from `@createcms/react/media/image`,
which carries no client boundary and runs in server components:
`getAssetImage(asset, options)` returns the `AssetImage`
(`{ src, srcSet, sizes, width, height, sources, placeholder, objectPosition, provenance, provenanceLabel, missing }`),
`variantUrl(asset, { w, format })` the URL of the smallest existing
rendition at least `w` wide (or `null`), `buildSrcSet(asset, format)` and
`objectPositionOf(focal)`.

For `next/image`, point `images.loaderFile` at
`@createcms/react/media/next-loader` and set `images.deviceSizes` and
`images.imageSizes` to the rendition widths (`[320, 640, 1280, 1920]` by
default). The loader snaps every requested width up to the next rendition
width, so Next never asks the asset endpoint for a width outside the ladder.
`createImageLoader({ widths, format })` builds one for other ladders or
frameworks (Astro `getImage`, Nuxt image providers).

## Usage parts

`Usage` shows where an asset is used, from
[`getAssetUsages`](/docs/reference/media#getassetusages). It works outside
`Media.Root` (in an asset detail panel or before archiving) and reads its
strings from the nearest catalog (`messages.usage`).

```tsx
import { Usage, createEditorHrefAdapter } from '@createcms/react/media';

<Usage.Root
  client={cmsClient.media}
  assetId={asset.id}
  editorHref={createEditorHrefAdapter('/admin/editor')}
>
  <Usage.Count />
  <Usage.ScopeSwitch />
  <Usage.MissingAltFilter />
  <Usage.List>
    {(item) => (
      <Usage.Item>
        {item.title}
        {item.occurrences.map((occurrence) => (
          <Usage.Occurrence key={occurrence.path} occurrence={occurrence}>
            {occurrence.propertyKey}
          </Usage.Occurrence>
        ))}
      </Usage.Item>
    )}
  </Usage.List>
  <Usage.Empty />
  <Usage.LoadMore />
</Usage.Root>;
```

| Part | Element | Description |
| --- | --- | --- |
| `Usage.Root` (`UsageRootProps`) | `section` | Runs `useAssetUsages` for `assetId` with `client`, `scope`, `missingAlt` and `limit`; `editorHref` defaults to `createEditorHrefAdapter()`. `aria-label` is `usage.title`; `data-scope` and `data-loading` reflect the query. |
| `Usage.Count` (`UsageCountProps`) | `p` | "Used on N pages", plus `usage.hiddenRoots` for roots outside the scope. Renders nothing before the first page. |
| `Usage.ScopeSwitch` (`UsageScopeSwitchProps`) | `select` | The scopes `live`, `published` and `history`. |
| `Usage.MissingAltFilter` (`UsageMissingAltFilterProps`) | `label` | A checkbox that keeps only image usages without alt text. |
| `Usage.List` (`UsageListProps`) | `ul` | Calls `children(item)` for every `MediaUsageItem`. |
| `Usage.Item` (`UsageItemProps`) | `li` | One root; `data-status` is `published`, `scheduled` or `draft`. |
| `Usage.Occurrence` (`UsageOccurrenceProps`) | `a` | Links into the editor at one `MediaUsageOccurrence`; an image usage without alt text opens with the alt field focused (`focus=alt`). `data-alt-state` carries the alt-text state. |
| `Usage.Empty` (`UsageEmptyProps`) | `p` | Renders once the query finished without any usage (`usage.empty`). |
| `Usage.LoadMore` (`UsageLoadMoreProps`) | `button` | Loads the next page; absent when there is none (`usage.loadMore`). |

`EditorHrefAdapter` (`{ build(target) }`) turns an occurrence
(`{ rootId, collection, branchId, blockId, path, focus }`) into a link.
`createEditorHrefAdapter(base = '/editor')` builds
`<base>/<collection>/<rootId>?block=...&path=...&branch=...&focus=alt`; pass
your own adapter for another editor.

The response types are `MediaUsagePage` (`{ total, items, nextCursor }`),
`MediaUsageItem`, `MediaUsageOccurrence` and `MediaUsageScope`
(`'live' | 'published' | 'history'`).

## Drag and drop

Items carry their asset ids natively as `application/x-createcms-asset+json`
(`{ ids, version: 1 }`, see `readAssetDrag` in Media core), plus
`text/uri-list` and `text/plain` with public URLs and, for one public asset,
Chrome's `DownloadURL` (drag to the desktop). A drag carries the selection
when the dragged item is part of it, else that item alone; several items get
a drag image with their count (`move.dragCount`). Folder tiles, tree items and
crumbs are drop targets: `useFolderDrop(folderId, options)` gives any element
that behaviour (`FolderDropOptions`: `onDwell` after `DROP_DWELL_MS`, `files`,
`intake`, `disabled`; `FolderDropState`: `over`, `kind`, `flash` for
`DROP_FLASH_MS`). Invalid targets (the assets' own folder, a folder into
itself or a descendant) show no indicator. `folderDragProps(folderId)` makes
an element a folder drag source (`FOLDER_DRAG_TYPE`), and
`useDropOverlay(enabled)` tracks OS file drags over the window
(`DropOverlayState`). Every drag has a non-dragging alternative: the "Move
to" tree in pick mode, `Intake.Input` and `Intake.FolderInput`.

## Hooks

### `useMediaLibrary`

Returns `MediaLibrary`: the whole `MediaStoreState`, `dispatch`, the loaded
`assets`, the subfolders of the open folder (`folders`) and shortcuts
(`openFolder`, `setFilter`, `setLayout`, `refresh`). Re-renders on every
change; prefer `useMediaStore(selector)` for a narrow subscription.

### `useMediaStore`, `useSelector`

`useMediaStore(selector, isEqual?)` subscribes to a slice of the enclosing
root's store (shallow equality by default). `useSelector(store, selector,
isEqual?)` does the same for any `ReadableStore` (`{ subscribe, getState }`).

### `useMediaCollection`, `useMediaAsset`, `useGridLayout`

`useMediaCollection()` returns the collection slice (query, ids, assets by
id, cursor, total, status) plus `assets` in order. `useMediaAsset(id)`
returns one loaded asset or `null`. `useGridLayout(options)` returns the
`CollectionLayout` of the collection for the current viewport and layout
mode.

### `useMediaSelection`

Returns `MediaSelection`: `{ selected, count, allMatching, hidden, mode,
canSelectAllMatching, total, select, toggle, selectAll, selectAllMatching,
clear }`.

### `useBulkActions`

`useBulkActions(itemId?)` returns the registered actions for the selection
(or one asset) as `BulkActionItem`s with whether each can run and its label.

### `useMediaFilter`, `useMediaFacets`

`useMediaFilter()` returns `MediaFilter`: `{ filter, active, set(patch, {
debounce }), clear() }`. `useMediaFacets()` returns the `MediaFacets` of the
current filter, refetched immediately on every change (a stale request is
aborted), or `null`.

### `useMediaEvent`

`useMediaEvent(type, listener)` subscribes to a store event while mounted:
`asset:uploaded`, `asset:updated`, `asset:replaced`, `asset:moved`,
`asset:archived`, `asset:restored`, `folder:changed`, `selection:changed`.
A detail panel reloads on `asset:replaced` without knowing the usage panel.

### `useMediaUploads`

Returns the `MediaUploadState` of the client (`client.useUploadAssets()`).
It lives in its own context so progress ticks re-render only the upload
parts.

### `usePreview`, `useAssetDetail`, `useDownloads`

`usePreview()`, `useAssetDetail()` and `useDownloads()` expose the preview,
the detail form and the archive downloads of the nearest `Media.Root`
(see `Preview.*`, `Detail.*` and `Download.*`). `useImageField()` and
`useCropEditor()` read the enclosing `ImageField.Root` and `Crop.Root`.

### `useMediaContext`, `useMediaAnnouncer`

`useMediaContext(componentName)` returns `MediaContextValue`
(`{ store, assetUrl, announce }`) and throws
`<componentName> must be used within a Media.Root component.` outside the
root. `useMediaAnnouncer()` returns the root's `announce(message,
politeness)` (a no-op outside one), for your own parts.

### `useAssetImage`

`useAssetImage(asset, options)` is `getAssetImage` memoized, with
`provenanceLabel` taken from the catalog (`messages.image.provenance`) unless
`options.provenanceLabels` is set. `options` (`AssetImageOptions`):
`sizes`, `widths`, `formats`, `focal`, `placeholderDataUrl`,
`provenanceLabels`.

### `useAssetUsages`

`useAssetUsages(client, { assetId, scope, missingAlt, limit })` returns
`UseAssetUsagesState`: `{ status, error, total, items, hasMore, scope,
missingAlt, setScope, setMissingAlt, loadMore, reload }`. Changing the scope
or the filter starts over; call `reload()` after a replace or an edit.
`useUsage()` returns the same state from the nearest `Usage.Root`.

### `useAssetUsageCounts`

`useAssetUsageCounts(client, assetIds, scope = 'live')` returns
`Record<assetId, { roots, published }>` for grid badges. The requests of every
component in one frame go out as a single `getAssetUsageCounts` call per
client and scope. Counts are cached until
`invalidateAssetUsageCounts(client, assetIds?)` drops them (all of them
without `assetIds`).

### `useMediaMessages`

`useMediaMessages()` returns `MediaMessagesContextValue`
(`{ messages, format }`): the merged catalog and locale-bound formatters of
the nearest `Media.Root`, or the defaults outside one.

## Messages

Every visible string and accessible name comes from a `MediaMessages`
catalog. `defaultMediaMessages` is English; pass a partial
`MediaMessagesInput` as `Media.Root`'s `messages` to translate it, and
`mergeMediaMessages(input)` merges one yourself. Static entries are
strings; entries with parameters are `MediaMessageFn<P>`, called as
`(params, format)`, where `format` is a `MediaFormatters` object bound to the
`locale`:

| Formatter | Output |
| --- | --- |
| `bytes(n)` | `Intl.NumberFormat` unit style, unit picked by magnitude (byte, kilobyte, megabyte, gigabyte) |
| `number(n)`, `percent(fraction)` | `Intl.NumberFormat` |
| `date(value)` | `Intl.DateTimeFormat`, medium date and short time |
| `eta(seconds)` | `Intl.RelativeTimeFormat` in seconds, minutes or hours |
| `plural(count)` | `Intl.PluralRules` category |
| `apple` | `true` on macOS and iOS, for `shortcut` labels |

`createMediaFormatters(locale)` builds the same object outside React.

```tsx
<Media.Root
  client={cmsClient.media}
  locale="de-DE"
  messages={{
    folder: { root: 'Mediathek', path: 'Ordnerpfad' },
    selection: {
      count: ({ count }, format) =>
        `${format.number(count)} ${format.plural(count) === 'one' ? 'Datei' : 'Dateien'} ausgewählt`,
    },
  }}
>
```

Parts never render a server message. An error code is translated with
`mediaErrorMessage(messages, code)`: codes in `MediaErrorCode` map to
`messages.error[code]`, any other code to `messages.error.unknown`.
`MediaTypeLabel` keys `messages.type`, one label per `MediaType`.
