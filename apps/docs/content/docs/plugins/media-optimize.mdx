---
title: Media optimize
description: Client-side resize, compress, and WebP conversion before upload.
---

The media optimize plugin processes images in the browser before they are uploaded: it resizes, compresses, and optionally converts to WebP. It is a client-only plugin. Optimization never blocks an upload: a file that cannot be optimized is uploaded unchanged, with a warning.

## Installation

### Add the client plugin

```ts title="lib/cms-client.ts"
import { createCMSClient } from '@createcms/core/react';
import { mediaOptimizeClient } from '@createcms/core/plugins/media-optimize';
import type { cms } from './cms';

export const cmsClient = createCMSClient<typeof cms>()({
  baseURL: '/api/cms',
  plugins: [
    mediaOptimizeClient({
      compress: { quality: 82 },
      resize: { maxSize: 2000 },
      convert: { format: 'webp' },
    }),
  ],
});
```

### WebP in Safari

Safari's canvas cannot encode WebP. To convert there, install the WASM encoder and pass a loader. The import must sit in your app code so your bundler emits the `.wasm` file; it is called only after the native probe fails, so other browsers never download it.

```bash
npm install @jsquash/webp
```

```ts
mediaOptimizeClient({
  convert: { format: 'webp' },
  webpEncoder: () => import('@jsquash/webp/encode'),
});
```

Without `webpEncoder`, Safari uploads the original file and reports `optimize_unsupported`.

## Usage

With the plugin installed, `cmsClient.media.useUploadAssets().upload(files)` optimizes every image before signing. Opt out per call with `upload(files, { optimize: false })`. Each ledger entry carries the outcome in `entry.optimize`:

```ts
type CMSMediaUploadOptimizeInfo = {
  optimized: boolean;
  bytesBefore: number;
  bytesAfter: number;
  warnings: { code: string; message: string }[];
};
```

To optimize without uploading, use `cmsClient.optimize.useOptimize(file, overrideConfig?)` in React, or the standalone `optimizeImage(file, config)` and `optimizeFiles(files, config)`. `optimizeImage` never rejects; `OptimizeResult` carries `file`, `optimized`, `bytesBefore`, `bytesAfter`, an optional `originalVariant` and an optional `warning`.

## Options

All options are optional. Without `resize`, `compress` and `convert` the plugin changes nothing.

| Section | Field | Type | Default | Description |
| --- | --- | --- | --- | --- |
| | `enabled` | `boolean` | `true` | Auto-optimize on upload. `false` registers no auto-optimizer, so `upload(...)` sends the original bytes. |
| `compress` | `quality` | `number` | `82` | JPEG/WebP encode quality, 1 to 100. Also used when only `resize` or `convert` is set. PNG ignores it. |
| `resize` | `maxSize` | `number` | none | Downscale so neither side exceeds this many pixels. Without it, images keep their dimensions. |
| `convert` | `format` | `'webp'` | none | Encode the output as WebP. |
| `convert` | `storeOriginal` | `boolean` | `false` | `optimizeImage` also returns `originalVariant`, a resized copy in the input format. Auto-upload sends only the primary file. |
| | `keepIfSmallerRatio` | `number` | `0.9` | Without a downscale, the re-encoded file is used only if it is at most this fraction of the input size. |
| | `webpEncoder` | `() => Promise<WebpEncoderModule>` | none | WebP encoder for browsers without native canvas WebP encoding. |

## What gets optimized

Only JPEG, PNG and WebP are re-encoded. These are uploaded byte-identical:

- Non-image files.
- SVG, GIF, ICO, BMP, AVIF, TIFF, HEIC/HEIF and every other image type.
- Animated WebP and APNG.
- Files whose first 256 KB carry an IPTC `DigitalSourceType` XMP property or a C2PA manifest. A canvas re-encode drops all metadata, including these provenance markers.

Files are optimized one at a time, so only one decoded bitmap is held in memory. The output name and type always follow the encoded format (`photo.jpg` becomes `photo.webp`), and an encode that returns another type than requested is discarded.

### Warnings

| Code | Meaning |
| --- | --- |
| `optimize_unsupported` | Excluded format, animated image, or WebP output in a browser without an encoder. |
| `optimize_skipped_provenance` | The file carries IPTC `DigitalSourceType` or a C2PA manifest. |
| `optimize_mislabel` | The encoder produced another type than requested. |
| `optimize_failed` | Decoding, importing the fallback encoder, loading its WASM binary or encoding threw. |

This plugin runs entirely in the browser, so there are no HTTP errors and no error codes on `$ERROR_CODES`.
