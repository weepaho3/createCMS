# Security Policy

## Supported versions

createCMS is pre-1.0 and under active development. Security fixes are applied to
the **latest published `0.x` release** and the `main` branch only; older versions
are not patched. When 1.0 ships, this policy will list the supported release lines.

## Reporting a vulnerability

Please **do not** open a public issue for security problems. Report privately via
either channel:

- **Preferred:** GitHub's [private vulnerability reporting](https://github.com/weepaho3/createCMS/security/advisories/new)
  ("Report a vulnerability" on the repository's **Security** tab).
- **Email:** steffen.schlabbach@brandpfeil.de — include a description and, if
  possible, a minimal reproduction.

We aim to **acknowledge your report within 72 hours** and will keep you updated as
we work on a fix. Please give us a reasonable window to release a patch before any
public disclosure; we are glad to credit you in the advisory unless you prefer to
remain anonymous.
